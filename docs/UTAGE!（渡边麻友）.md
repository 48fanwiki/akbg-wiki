# 简介

《UTAGE!》（ウタゲ!）是TBS电视台自2014年4月21日-2015年9月28日每周一深夜0:08 - 0:38 （日本时间，周二凌晨）放送的音乐类综艺节目。常规番组结束后，不定期播放SP。

本节目一边介绍由1970、80、90、00年代的名曲、热门歌曲等各种各样主题组成的《UTAGE排行榜》，一边由本节目的歌手们（UTAGE嘉宾）演唱别人的热门歌曲，

以”一起看、一起听、一起唱、一起开心、一起参与”为宗旨的崭新的音乐类娱乐节目。

MC：中居正広

助理MC：渡辺麻友（自2020年起不再担任）

官网&维基：《节目官网》、《日文维基》
