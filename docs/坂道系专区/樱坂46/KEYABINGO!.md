# KEYABINGO!

## 简介

- 《KEYABINGO!》是日本电视台自2016年7月5日(7月4日深夜)起放送的深夜综艺节目，于每周一深夜25:29-25:59(日本時間)播出。

- 本節目為欅坂46繼《欅会不会写》之後的第二個專屬冠名節目，同時，播放時段也接檔了《NOGIBINGO!6》

- 節目主持人：「サンドウィッチマン」(三明治人)

- 官網&維基：《[节目官网](http://www.ntv.co.jp/KEYABINGO/)》、《[日文维基](https://ja.wikipedia.org/wiki/KEYABINGO!)》
