# 欅って、書けない？

## 簡介

- 《欅會不會寫》（欅って、書けない？）是2015年10月5日（4日深夜）開始，每周日深夜24:35 - 25:05（日本時間），於東京電視台放送。

- 本節目為於2015年8月成立的日本女子組合欅坂46（原名為「鳥居坂46」）首個專屬冠名節目。

- 節目主持人：土田晃之、澤部佑 (ハライチ)

- 官網&維基：《[節目官網](http://www.tv-tokyo.co.jp/keyaki/)》、《[日文維基](https://goo.gl/asqKbr)》
