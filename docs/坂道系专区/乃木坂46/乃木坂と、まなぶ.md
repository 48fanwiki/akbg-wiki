# 乃木坂と、まなぶ

## 简介

和乃木坂的妹子们一起上课吧！！ 官方网址→→→《[这里](http://www.asahi.com/edu/nogizaka46/)》

人生论篇名字为《乃木坂46 日々是勉強》也是朝日新闻系列，AKB的人生论系列姐妹篇

上课篇为妹子们跟着老师一起学习课程，还会分班讨论。。。这科普简直良心。

采访篇即两个妹子采访一名特殊职业的名人，从他们身上学习。
