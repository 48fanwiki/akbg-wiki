# 乃木坂46 佐藤枫 音色遗产

## 简介

爱知电视台40周年纪念节目「乃木坂46佐藤枫音色遗产～爱知69市区町村的收集美音～」将于10月3日（星期一）开始！
爱知县69个市区町村1个区域各播放1周 （每周6次）。
美食、观光、历史遗产、传统工艺、自然遗产...以只有在当地才能听到的「独一无二的音色」为关键词，介绍当地极具魅力的景点。
来自爱知县的乃木坂46的佐藤枫将出演。

详情：https://www.nogizaka46.com/s/n46/news/detail/65831?ima=4104&pri1=202209
