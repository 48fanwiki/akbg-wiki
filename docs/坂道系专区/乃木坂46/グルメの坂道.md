# グルメの坂道

## 简介

- 第一季
乃木坂46的美食报道综艺节目「グルメの坂道」在手机APP上开始放送，第一集是斋藤飞鸟
从12月9日（周三）起，乃木坂46以接力形式挑战美食报道的原创综艺「グルメの坂道」，将在手机强化型视频软件「smash.」上开始放送。
在「グルメの坂道」这档节目中，乃木坂46的成员们将到访那位每年吃过1000家以上店铺的Fallindebu所推荐的餐厅，品味“时下最应当吃的一道菜”。
第一集由斋藤飞鸟出演。在斋藤用手机亲自拍摄的视频中，不仅收录了自拍，以及餐馆老板的自然表情等内容，观众还能切身体会到斋藤视线下的氛围。
另外，12月中旬预定由向井叶月、星野南出场。来年1月起预定由乃木坂46的成员陆续参加。
「グルメの坂道」将于每周一、三更新。预计共30集。

- 第二季
之前在「smash.」配信的『グルメの坂道』第二季『ヤミー！』今日开始每周一配信，第一集为渡辺みり愛。
番組名：ヤミー！
配信日時：2021年4月26日（月）スタート、 以降毎週月曜日18時に新エピソードアップ
プロデュース：秋元康
総合演出：田中経一
