# ライオンのグータッチ

## 简介

- ライオンのグータッチ（狮子的对拳）是从2016年4月2日开始在富士电视台早上时段播出的节目。乃木坂46成员西野七瀬首次担任MC一职。
- 节目主旨是为了给在体育或音乐等领域拼命努力了却得不到结果的孩子们应援，节目组请出相关的专家来给予全力的支持和指导，让孩子们能实现目标、完成梦想。
- MC：佐藤隆太、博多大吉、西野七瀬
- 《[节目官网](http://www.fujitv.co.jp/b_hp/liongootouch/)》《[日文维基](https://ja.wikipedia.org/wiki/%E3%83%A9%E3%82%A4%E3%82%AA%E3%83%B3%E3%81%AE%E3%82%B0%E3%83%BC%E3%82%BF%E3%83%83%E3%83%81)》
