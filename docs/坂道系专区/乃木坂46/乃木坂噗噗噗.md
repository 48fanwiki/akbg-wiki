# 乃木坂噗噗噗

## 簡介

- サガラとキヨトの乃木坂ぷぷぷ（相乐和清人的乃木坂噗噗噗）由埼玉电视台制作并播放，是一个把世间让人噗噗噗的东西收集起来，为大家送去欢笑的脱力系综艺节目。埼玉県出身乃木坂46成员相楽伊織，与Bad boys的清人的联手，首度挑战冠名番组MC位置；乃木坂46内其他埼玉出身的成员也会作为周替MC出演。本节目的另一个看点是每周有不同的乃木坂46成员担任番组的旁白解说。然而埼玉电视台于2015年11月在其官方网页上突然宣布节目中止，最终只播出了7集。《[日文维基](https://ja.wikipedia.org/wiki/%E3%82%B5%E3%82%AC%E3%83%A9%E3%81%A8%E3%82%AD%E3%83%A8%E3%83%88%E3%81%AE%E4%B9%83%E6%9C%A8%E5%9D%82%E3%81%B7%E3%81%B7%E3%81%B7)》
- MC：清人(Bad Boys)、相楽伊織
- 周替：秋元真夏、中田花奈、井上小百合、斎藤ちはる、佐々木琴子、新内眞衣
