# ACミラン・チャンネル ミラノミラン

## 簡介

- AC米蘭頻道(ACミラン・チャンネル)是BS12 TwellV旗下足球頻道，主要轉播AC米蘭的球賽及報導AC米蘭最新資訊。

- AC米蘭頻道自2014年10月13日開始，推出六十五集迷你節目Milano Milan(ミラノミラン)，介紹米蘭的美食、時尚和文化等，由乃木坂成員深川麻衣擔任節目旁白，逢星期一至五晚上9:55(日本時間)播映。

- 官網：《[節目官網](http://www.twellv.co.jp/event/milanchannel/milanomilan-01.html)》
