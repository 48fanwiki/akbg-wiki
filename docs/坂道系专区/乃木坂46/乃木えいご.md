# 乃木えいご

## 简介

- 《乃木えいご》（乃木坂英语）是2015年6月28日开始，每个月一集在深夜23:30 ~ 24:00（日本时间），由TBS放送的乃木坂46冠名综艺节目。

- 这是为了在2020年的東京奥运会到来时，实现乃木坂46成为国际化偶像这一目标而开设的节目。

- 同时每期还将会有一名或多名非固定乃木坂46成员来堂参与节目。

- 节目固定班底：能条爱未、川后阳菜、北野日奈子、和田玛雅、鈴木拓、安河内哲也(講師)

- 随着平田梨奈在AKB48毕业，她在2016年10月播出的EP13之后不再担任节目固定班底。

- 2018年4月播出的EP26之后，能条爱未、川后阳菜、北野日奈子、和田玛雅不再担任节目固定班底。

- 2018年6月播出的EP27之后，节目新固定班底：斉藤優里、新内眞衣、樋口日奈、鈴木拓、安河内哲也(講師)。

- 2019年3月播出的EP35之后，和田玛雅重返固定班底，EP37斉藤優里畢業，EP38佐藤枫加入新固定班底。

- 2021年1月最终回完结。

- 官网&维基：《[节目官网](http://t.cn/Rf3l2Jo)》《[日文维基](http://t.cn/Rf3lJBz)》
