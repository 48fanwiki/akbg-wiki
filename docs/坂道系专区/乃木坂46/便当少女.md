# 便当少女

## 简介

- 《弁当少女》（べんとうしょうじょ）是2013年10月4日至2014年3月28日每周五深夜1:29-1:44放送的音乐情报节目。（[日文维基](http://t.cn/RcEICfi)）

- 除第一回外，每周由橋本奈々未、松村沙友理、若月佑美三人交替出演。

- 毎回登场的成员将带着自己原创的便当拜访一组艺人嘉宾，聊各种各样的话题。

- 另外就是介绍最新的音乐、娱乐情报，榜单之类的。
