# 乃木坂在哪

## 简介

《乃木坂，在哪里？》（乃木坂って、どこ?），简称斗狗，是由爱知电视台制作，于东京电视网播映的综艺节目，现每周日深夜24:00 - 24:30（日本时间）放送。

本节目于2011年10月2日起开始播映，为于2011年8月成立的日本女子组合乃木坂46首个专属冠名节目。主持人是香蕉人（设乐统和日村勇纪）。

根据官方网站的描述，乃木坂46的成员于节目内会有各样挑战，从中突出成员的“唱功”、“舞蹈能力”、“演技”、“拼命”、“努力”等等。
