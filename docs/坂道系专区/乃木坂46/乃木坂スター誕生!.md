# 乃木坂スター誕生!

## 简介

- 日本电视台每周一晚25:29-25:59（每周二凌晨1:29-1：59）播出
- 节目内容为成员挑战昭和、平成時代的經典歌曲
- 第一季&第二季MC为PEKOPA（秀平、松陰寺太勇），第三季MC为オズワルド（畠中悠、伊藤俊介）
- 第一季四期生出演，第二季前輩成員也會一同出演，第三季、第四季五期生出演
- 《[節目官網](https://www.ntv.co.jp/nogistar/)》《[第一二季日文維基](https://ja.wikipedia.org/wiki/乃木坂スター誕生!)》《[第三季日文維基](https://ja.wikipedia.org/wiki/新・乃木坂スター誕生!)》《[第四季日文維基](https://ja.wikipedia.org/wiki/超・乃木坂スター誕生!)》
