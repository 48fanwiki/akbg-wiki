# ポケTの坂道でおじんじょ

## 简介

- 《坂道正座》是2019年7月20日起在新广岛电视台播出的谈话节目。广岛县出身的乃木坂46成员和田玛雅和吉本坂46成员藤井菜央，通过各种各样的体验学习了意外地不知道的广岛。节目名“おじんじょ”在广岛方言中是“正座”的意思。
- 放送時間：2019年7月20日 - 2020年10月10日：毎週土曜11:45 - 11:50；2020年10月18日 -  ：毎週日曜11:45 - 11:50
