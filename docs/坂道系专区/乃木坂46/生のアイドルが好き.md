# 生のアイドルが好き

## 简介

- 生のアイドルが好き（喜欢活生生的偶像）是由乃木坂46成员中田花奈、松村沙友理主持的音乐情报综艺节目，从2013年4月18日开始每个月一回在niconico进行网络直播，之后会在偶像专属频道Pigoo进行网络配送。节目每集会邀请若干组女子偶像组合来到演播室，包括乃木坂46，通过各种各样的谈话和游戏环节，来和喜欢偶像的两位主持搞好关系。
- Niconico的直播日期和Pigoo的配送日期并不相同，Pigoo除了配送节目的本篇之外，还包括节目直播开始前的小花絮和结束后两位主持的回顾总结等未公开部分。
- 《[日文维基](https://ja.wikipedia.org/wiki/%E7%94%9F%E3%81%AE%E3%82%A2%E3%82%A4%E3%83%89%E3%83%AB%E3%81%8C%E5%A5%BD%E3%81%8D)》《[Pigoo页面](http://pigoo.jp/pigoohd/products/detail.php?product_id=25387)》
