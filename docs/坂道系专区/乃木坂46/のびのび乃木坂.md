# のびのび乃木坂

## 简介

- 《のびのび乃木坂》是音樂番組“GiRLPOP TV”裡的冠名單元節目，在2012年9月15日到2013年6月26日期间播出。

- “GiRRLPOP TV”共20期，但因为130515举办了演唱会SP，所以本环节一共19期。其中前7回为每月放送一集，第8回开始改为周放送。

- 每集由三名成員負責出演，到访時下的話題場所並親身體驗各種不一樣的活動，节目中可以看見成員們少見的出外景情況和UM們活躍的樣子。
