# のぎ天

## 简介

- 《乃木天》（のぎ天 ），是乃木坂46 Under Girls的专属番组。作为偶像，成员们会在番组里接受各种各样的企划挑战!

- 这是由楽天SHOWTIME赞助，第一季自2014年7月11日开始，于每周五15:00（日本时间）免费放送的综艺节目。第一季于2015年7月完结，由**乃木坂高尔夫俱乐部**接档。

- 2016年6月17日第二季开播，由免费配信改为收费配信。

- 原视频播放列表在官网页面下方，播放视频需要日本IP。《[第一季页面](http://video.rakuten.co.jp/content/110967/)》《[第二季页面](http://video.rakuten.co.jp/content/186164/)》
