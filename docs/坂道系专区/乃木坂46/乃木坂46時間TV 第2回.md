# 乃木坂46時間TV 第2回

## 簡介

- 為纪念乃木坂46第二张专辑「それぞれの椅子」发售，乃木坂46再次舉辦「乃木坂46時間TV」企画，第2回从日本時間2016年6月10日晚上9點到2016年6月12日晚上7點，連續46小時無間斷進行網上直播。本次节目内容包括成员的个人十分钟番组、成员presents的企画、大受欢迎的狼人游戏、军团全国外景巡回对决、乃木坂画伯绘画歌环节、乃木坂46国民投票竞赛、二期生的生诞祭以及深川麻衣的毕业企画等等。

- 番组MC
第一组：白石麻衣、橋本奈々未
第二组：衛藤美彩、西野七瀬
第三组：中元日芽香、井上小百合
第四组：星野みなみ、堀未央奈
- 節目特設網頁：http://www.nogizaka46.com/46tv/2nd
