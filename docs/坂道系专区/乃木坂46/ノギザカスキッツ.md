# ノギザカスキッツ

## 简介

- 乃木坂46四期生新常规节目，外景节目「乃木坂どこへ」的下一章，「ノギザカスキッツ」开始了！
- 主题是认真地挑战短剧！到底会展开什麼樣的短剧呢...
- 第一季從2020年6月16日到10月27日，每週二(週一深夜)1:29～1:59(日本時間)，在日本TV放送
- 第二季從2020年11月10日，每週二(週一深夜)1:29～1:59(日本時間)開始播出
- MC：再见了青春之光（森田哲矢、東ブクロ）
- 出演成員為四期生，新四期生的5人也会加入，power up的16人体制为大家放送
- 從第二季開始，三期生也會一同參戰！！

- 《[節目官網](https://www.ntv.co.jp/nogisuki/)》《[日文維基](https://ja.wikipedia.org/wiki/ノギザカスキッツ)》
