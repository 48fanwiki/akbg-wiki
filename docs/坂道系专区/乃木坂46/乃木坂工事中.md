# 乃木坂工事中

## 简介

- 《乃木坂工事中》（乃木坂工事中）是2015年4月19日开始，每周日深夜24:00 - 24:30（日本时间），由东京电视台放送的乃木坂46冠名综艺节目。

- 本节目为乃木坂46继2011年10月2日 - 2015年4月13日放送的《乃木坂在哪》之后的第二个专属冠名节目，同时，播放时段也接档了《乃木坂在哪》。

- 本节目每周选一名成员，收录她想做的节目并发表。与《乃木坂在哪》相比，本节目将各个成员单独作为企划主人公，将更加展现出各个成员的特色与魅力。(ep25後取消)

- 节目主持人：香蕉人（设乐统、日村勇纪）。

- 官网&维基：《[节目官网](http://www.tv-aichi.co.jp/nogi-kou/)》、《[日文维基](https://ja.wikipedia.org/wiki/乃木坂工事中)》
