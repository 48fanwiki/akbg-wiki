# 乃木坂どこへ

## 简介

- 《乃木坂去哪》（乃木坂どこへ）是日本电视台10月22日开始，每周二凌晨1：29～1：59（日本时间）播出的，接档《NOGIBINGO!》的全外景综艺节目。
- 没有一般综艺的“入门”、“规矩”、“固定概念”，挑战的是真正没有束缚的“悠闲之旅”。成员将前往各种各样的街道，发现并挑战自己的第一次。没有台本、没有规矩、无法预测、“规格外”的外景综艺。
- 本篇播出之后Hulu会播出未公开影像
- 主持人：さらば青春の光（森田哲矢、東ブクロ）
- 出演成员为四期生：遠藤さくら、賀喜遥香、掛橋沙耶香、金川紗耶、北川悠理、柴田柚菜、清宮レイ、田村真佑、筒井あやめ、早川聖来、矢久保美緒

- 《[节目官网](https://www.ntv.co.jp/nogidoko-e/)》《[日文维基](https://ja.wikipedia.org/wiki/乃木坂どこへ)》
