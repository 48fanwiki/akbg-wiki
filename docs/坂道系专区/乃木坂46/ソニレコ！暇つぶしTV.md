# ソニレコ！暇つぶしTV

## 简介

《Sonyrecord消磨时间TV》是乃木坂46与索尼音乐合作的Youtube音乐节目，13年10月份开始每月第二、第四个周三播放.

2014年4月11日起，放送时间改为每周一集，每周五更新。

主持人：高山一実、深川麻衣；其它乃木坂成员也经常作为嘉宾出现。
