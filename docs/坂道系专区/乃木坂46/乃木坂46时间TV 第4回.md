# 乃木坂46时间TV 第4回

## 簡介

- 2020年6月19日（周五）晚上7点~21日（周日）下午5点的46个小时间，将决定放送『乃木坂46小时TV Abema独占放送「即使远离，我们也是在一起的！』
- 这次是第4次，也将在「aAbema」独占放送，有成员们自己思考的10分钟左右的节目『乃木坂电视台』，能看到成员们穿着睡衣玩桌游，深夜惯例企划『狼人殺』等为首，首次尝试1~4期期別分开的环节『1期2期3期4期・期别冠名节目环节』等。还准备和「Abema」的很多人气节目进行合作。其他企划也会在放送前发表，敬请期待。
- 2020年5月23日（周六）晚上10点开始的官方事前特别节目『Abema独占放送 乃木坂46成员大集合！46分线上记者招待会&乃木坂46分TV』的放送。乃木坂46的成员们前无古人的第一次完全线上记者招待会，还有关于這次46小时TV的看点进行介绍。成员45人在线上聚集举行的记者招待会，由秋元真夏和梅泽美波进行主持，詢問成员们關于這次46小时TV的抱负以及节目企划相关的谈话。这边也请结合起来大家一起享受。
