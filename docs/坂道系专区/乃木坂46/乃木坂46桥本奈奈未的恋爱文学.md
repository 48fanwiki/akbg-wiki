# 乃木坂46桥本奈奈未的恋爱文学

## 简介

- 『乃木坂46 橋本奈々未の恋する文学』是橋本奈々未的个人冠名番组，由UHB（北海道文化放送）制作并在北海道当地放送，节目内容是介绍以北海道为舞台的小说。北海道旭川市出身、兴趣是读书的乃木坂46成员橋本奈々未，将带上一册书展开旅程，探访作为小说舞台的北海道各处，去发现她不知道的美景，与在那里生活的人相遇。节目通过她朗读小说中的不同段落，阿南亮子的原创音乐，以及美丽的影像来表现作品的世界观。节目结尾还附有乃木坂46成员介绍自己喜欢的一本书的小环节「乃木坂46Books」。这是一个传达阅读和北海道的魅力，充满地方色彩的知性的娱乐节目。
- 「乃木坂46 橋本奈々未の恋する文学-冬の旅-」在2016年2月18日（深夜24点25分）开始播出，连续五周播放，全五回。介绍村上春树的《挪威的森林》和《寻羊冒险记》，樱木紫乃的《Loveless》，以及渡边淳一的《魂断阿寒》四本小说。
- 好评之下，续篇「乃木坂46 橋本奈々未の恋する文学-夏の旅-」于2016年10月27日（深夜24点25分）开始播出，连续六周播放，全六回。会介绍宮下奈都的《羊と鋼の森》，渡辺淳一的《花埋み》和桜木紫乃的《蛇行する月》三本小说。
- 官网与维基：《[冬之旅篇](http://t.cn/RVHcqZh)》《[夏之旅篇](http://t.cn/RVzM3VA)》《[日文维基](http://t.cn/RVHcyrP)》
