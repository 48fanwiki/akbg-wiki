# ストレッチマン・ゴールド

## 簡介

- 《Stretchman》系列是从1994年开始的面向儿童的长寿节目。生駒里奈的新常规番组『Stretchman·Gold』由Stretchman·Gold的扮演者结城洋平，Stretchman·Legend的扮演者宇仁菅真，宇宙蜗牛型机器人麦麦的扮演者生駒里奈3人担任本节目的MC。
