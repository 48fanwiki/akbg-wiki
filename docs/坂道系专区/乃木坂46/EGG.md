# EGG

## 簡介

- 由生駒里奈、DAIGO担任MC的新节目，电子竞技相关节目《eGG》（esports Good Game）每个月一期，会介绍各类电子竞技游戏以及资讯，MC也会参与其中，非常有趣哦~
- 2020年3月20日后生驹里奈不再担任常驻MC
