# 特捜警察ジャンポリス

## 简介

- “特捜警察ジャンポリス”（JUMP UNDERCOVER MISSION POLICE）是东京电视台从2014年4月4日开始每周五傍晚时段放送的综艺节目。

- 生駒里奈作为节目中捜査本部的数据分析官出现，其他出演者还有中田敦彦、足立梨花等，此外乃团成员偶尔也会出现打酱油。节目内容主要是集英社发行的四本少年杂志的关联情报。节目于2019年3月30日完结。

- 《[官方网页](http://www.tv-tokyo.co.jp/anime/jumpolice/index2.html)》《[日文维基](https://ja.wikipedia.org/wiki/%E7%89%B9%E6%8D%9C%E8%AD%A6%E5%AF%9F%E3%82%B8%E3%83%A3%E3%83%B3%E3%83%9D%E3%83%AA%E3%82%B9)》
