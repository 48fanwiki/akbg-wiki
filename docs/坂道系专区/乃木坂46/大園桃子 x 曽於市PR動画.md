# 大園桃子 x 曽於市PR動画

## 简介

2018年6月，乃木坂46的大園桃子桑就任了曽於市特別宣传大使。
她在曽於市大隅町出生长大，于平成28年9月在3期生甄选中合格加入乃木坂46，并在之后出演了包含紅白歌合戦在内的很多电视节目。
这么可爱的大園桃子桑走遍曽於市「SOO GOOD」的场所拍摄的宣传视频即将公开！
她将会去到什么地方呢…视频将会分成5个为大家播出。敬请期待！
