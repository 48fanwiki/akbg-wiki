# 乃木坂46とダンスバトルズ

## 简介

- 《和乃木坂斗舞》是富士电视台系列从2022年4月5日开始每周二23:30-23:40（JST）播出的综艺节目和迷你节目。以在世界范围掀起热潮的舞蹈为特色，对以顶点为目标的个性丰富的职业舞者进行贴身采访，真实反映出对舞蹈的爱与纠葛的斗舞综艺节目。
- MC：乃木坂46、霜降り明星（せいや・粗品）、中野美奈子
