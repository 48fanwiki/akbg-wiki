# NOGIBINGO!

## 简介

- 《NOGIBINGO!》是日本电视台自2013年7月2日至2013年9月17日放送的深夜综艺节目，与姊妹节目《HKT48 猪骨魔法少女学院》于每周二深夜25时29分播出，各30分钟，总共60分钟。

- 本节目是以“乃木坂46如果在AKB48的主场，将AKB48做过的事情全都做一次，是否也能像AKB48一般成为全民偶像、甚至超越？”为基础企画出的综艺节目，主持人为猥琐冈田。  
为了达到这点，选择了同样是由日本电视台制作、AKB48最具代表性综艺《AKBINGO!》的摄影棚作为场地，连布景也不更换、直接将“NOGI”字样补丁打在“AKBINGO”牌子上，变成《NOGIBINGO!》。除节目名称仿效《AKBINGO!》外，节目各环节也都是复刻自《AKBINGO!》中的企画。用此方法加以验证同样的企画由不同的组合来进行时，是否会产生不同的综艺效果，以呼应其“实验节目”的定位。每集节目开始会有一个“本周的开场整人”小环节，以各种方式惊吓成员。而在节目末尾冈田也会根据该集节目中各成员的表现选出一位“最不成材的成员”，并施以一个小惩罚。

- 2014年1月10日至2014年3月29日播出第二季《NOGIBINGO!2》，主题为「超越AKB48」

- 2014年10月6日至2014年12月23日播出第三季《NOGIBINGO!3》，主题为「弱点克服」

- 2015年4月6日至2015年6月22日播出第四季《NOGIBINGO!4》，主题为「华丽的变身」

- 2015年7月13日至2015年9月28日播出第五季《NOGIBINGO!5》，主题仍为「变身」

- 2016年4月11日至2016年6月27日播出第六季《NOGIBINGO!6》

- 2016年10月11日至2016年12月26日播出第七季《NOGIBINGO!7》

- 2017年4月11日至2017年6月19日播出第八季《NOGIBINGO!8》，主题为「青春」

- 2017年10月16日至2017年12月25日播出第九季《NOGIBINGO!9》

- 2018年10月8日至2018年12月17日播出第十季《NOGIBINGO!10》

- 《[节目官网](http://www.ntv.co.jp/NOGIBINGO/)》《[日文维基](https://ja.wikipedia.org/wiki/NOGIBINGO!)》
