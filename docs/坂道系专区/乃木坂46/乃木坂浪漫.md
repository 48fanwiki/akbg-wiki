# 乃木坂浪漫

## 简介

《乃木坂浪漫》（のぎざかろまん）是2012年4月2日至9月27日，每周一至周四深夜放送的迷你节目。

乃木坂46的成员们将每日轮流登场，朗诵日本文学史中的名作中令人印象深刻的场面。

可用“ctl+F”寻找特定成员的朗诵集数。
