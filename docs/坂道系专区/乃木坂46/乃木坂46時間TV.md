# 乃木坂46時間TV

## 簡介

- 為慶祝乃木坂46正式出道四周年，乃木坂46舉辦「乃木坂46時間TV」企劃，由日本時間2016年2月20日早上4點至2016年2月22日(乃木坂46单曲出道纪念日)早上2點，連續46小時無間斷進行網上直播，節目包括成員個人十分鐘番組、團外媒體合作番組、成員對談及綜藝特集等等。除此之外，部分乃木坂46成員更組成多個小分隊在直播期間走訪日本大部分都縣，為慶祝出道四周年進行拍攝。

- 番组公认女主播
2月20日：秋元真夏、生田絵梨花（生田由于身体不适，当日前半段由高山一実暂代主持，于下午回归。）
2月21日：松村沙友理、若月佑美

- 節目特設網頁：http://www.nogizaka46.com/46tv/
