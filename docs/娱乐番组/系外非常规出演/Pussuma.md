# Pussuma

## 简介

《“ぷっ”すま》是朝日电视台放送的深夜节目。草彅剛（SMAP）与中山裕介每回与嘉宾进行各种各样对决的综艺节目。

节目从1998年10月5日开始放送。现在每周放送时间为周五深夜0:50 - 1:20。

本页收集的集数为有肥秋系成员出演的Pussuma，如发现缺漏欢迎补充。
