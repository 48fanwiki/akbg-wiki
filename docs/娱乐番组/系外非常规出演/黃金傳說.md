# 黃金傳說

## 简介

《黄金传说》（日语：いきなり!黄金伝説。；直译：《突如其来！黄金传说。》）是日本朝日台2000年4月18开始放送的综艺节目。目前播出时段为每星期四19:00至19:58（日本时间）。

该节目邀请艺人挑战各式各样的主题，如著名单元“一个月一万元节约生活”、“无人岛0元生活”、吃光连锁餐厅菜单上的所有产品等，以达成各式各样的“传说”。

本页收录的为有AKB48成员参与的黄金传说集数，如发现缺漏欢迎补充。
