# 寻宝大冒险 解谜大作战 TORE!

## 简介

《TORE全力大挑战》（日文原文：宝探しアドベンチャー 謎解きバトルTORE!，完整名称为“寻宝大冒险，解谜 Battle “TORE””，简称TORE!）是日本电视台的综艺游戏节目。

节目前身为“《DERO密室游戏大脱逃》”

节目的内容，是以队伍与队伍之间的对抗方式，于游戏内，取得一定数量的“黄金法老男像”（黄金のファラ男像），晋级成为最后奖金挑战赛的资格。

具体详细规则请戳→→→→→→《[这里](http://zh.wikipedia.org/wiki/TORE%E5%85%A8%E5%8A%9B%E5%A4%A7%E6%8C%91%E6%88%B0)》

本页收集的集数为有AKB出演的TORE，如发现缺漏欢迎补充。
