# めちゃ2イケてるッ! AKB合集

## 简介

- 《めちゃ2イケてるッ!》（Mechaike）是富士台週六晚間黃金時段的综艺节目，由岡村隆史、矢部浩之等人主持。（[官网戳这里](http://www.fujitv.co.jp/MECHA/index.html)）

- AKB Group的成员们参与过本节目的特辑SP与常规节目，其中“AKB单独企划SP”的几集更为出名，因为单独企划中AKB成员戏份最多，具体见下表。
