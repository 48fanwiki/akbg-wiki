# 密室谜综艺 DERO

## 简介

《DERO密室游戏大脱逃》（日语：密室謎解きバラエティー 脱出ゲームDERO!）简称《脱逃游戏DERO》是日本日本电视台的综艺游戏节目。‘DERO’的日文意思为‘出去’.

2011年7月6日推出后继节目“TORE全力大挑战(日语：宝探しアドベンチャー 謎解きバトルTORE!)”

挑战者使用自己的智力与体力，逃出在各式各样的装置及陷阱的密室为目标 ，节目主旨则是“亲身感受像电影一样的高潮！”【OK Now Begin!!】

具体详细规则请戳→→→→→→《[这里](http://zh.wikipedia.org/wiki/DERO%E5%AF%86%E5%AE%A4%E9%81%8A%E6%88%B2%E5%A4%A7%E8%84%AB%E9%80%83)》

本页收集的集数为有AKB出演的DERO，如发现缺漏欢迎补充。
