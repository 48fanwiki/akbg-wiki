# ジャネーノ

## 简介

《难道不是么》（ジャネーノ!?）是2014年4月28日至9月8日由富士系列电视台放送的Talk类综艺节目。共16回。

节目将从对艺能届各种情报帝手中拿来情报，再把各種爆料直接爆給事件主角，看他們如何回應。主持人也有可能被波及到。大家一起爆料，誰也無法預料結果

MC:後藤輝基、竹内友佳
