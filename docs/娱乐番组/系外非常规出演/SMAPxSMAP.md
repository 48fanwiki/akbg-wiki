# SMAPxSMAP

## 简介

- SMAP×SMAP是日本关西电视台与富士电视台共同制作，由杰尼斯偶像团体SMAP演出主持的综艺节目，日本时间每周一晚间10点播出。

- 节目内容以BISTRO料理、短剧、歌手演唱为主，1996年4月15日开播以来一直保持着甚高的收视率。随着SMAP宣布解散，节目于2016年12月26日结束。

- 本页收集的集数为有AKBG出演的SMAPxSMAP，如发现缺漏欢迎补充。
