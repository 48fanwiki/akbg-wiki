# 全員逃走中

## 简介

《全员逃走中》简称《RFM》或《逃走中》是日本富士电视台的综艺游戏节目，自2004年开始不定期播放。

《全员逃走中》为一街头生存游戏，参与游戏的“逃亡者”必须在一定限时内，在制作单位所划定的场地中，躲避“猎人”的追捕。成功躲避追捕可获得奖金，被抓到则奖金归零。

游戏过程中会不时穿插任务，增加游戏的难度及趣味性。本节目在2009年曾获得亚洲电视大赏的游戏或益智类奖项。

具体详细规则请戳→→→→→→《[这里](http://zh.wikipedia.org/wiki/%E5%85%A8%E5%93%A1%E9%80%83%E8%B5%B0%E4%B8%AD#.E8.A6.8F.E5.89.87)》
