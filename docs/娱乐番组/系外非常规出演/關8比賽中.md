# 關8比賽中

## 簡介

- 《關8比賽中》（関ジャニの仕分け∞），朝日電視台遊戲節目，逢週六19:54（JST）播出，每次57到60分鐘，有時也會有2小時特別節目。由關8主持，垂木勉擔任旁白作介紹以及說明。2011年4月6日開始播出；同年9月10日起，正式升格黃金時段節目。台灣緯來日本台的播出名稱為「關8比賽中」（原音配上中文字幕播出），從2012年12月開始播出，播放集數和日本不同，順序也不定，2014年10月緯來日本台改至每週日晚間5:30播出。节目于日本时间2015年3月21日完结。

### 企劃

- 太鼓達人節奏感對決
- 辨別出女裝男
- 辨別出能唱贏專業歌手的諧星唱將
- 對傑尼斯的愛的分類
- 辨別出混在小學生中的媽媽
- 辨別出實際上很弱的藝人
- 辨別出柔軟女王No.1
- Dance的分類
- 默契7

### 各項冠軍

- 卡拉OK冠軍：Mayj.
- 太鼓達人：大倉忠義
- 柔軟女王：須田亞香里
