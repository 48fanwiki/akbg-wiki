# DOWN TOWN DX

## 简介

- “DOWN TOWN DX”（ダウンタウンDX）是日本电视台于1993年10月21日开始每周四22:00 ~ 23:0放送的TALK类综艺节目，是DOWNTOWN（搞笑艺人组合）的冠名番组。
- 本页收集了AKB GROUP成员出演的DOWN TOWN DX 集数，如有发现缺漏欢迎补充。
