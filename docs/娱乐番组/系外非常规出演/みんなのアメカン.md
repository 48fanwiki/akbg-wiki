# みんなのアメカン

## 簡介

- NTV从12年1月7日（土曜日）12时55分开始放送的深夜节目。由雨后敢死队的两位：宫迫博之和萤原彻主持，每期和嘉宾一起参与做游戏的猜谜节目。4月19日起改名《みんなのアメカン》并升格至毎周四19：00 播出，添加固定司会佐佐木希等成员。
