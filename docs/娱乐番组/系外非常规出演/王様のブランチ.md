# 王様のブランチ

## 简介

《王様のブランチ》（King's Brunch）是TBS电视台每周六放送的广情報・综艺节目。（[官网戳这里](http://www.tbs.co.jp/brunch/)）

主要以介绍书籍、休闲、购物、电视、电影、美食、艺人等为主。
