# さんまのまんま

## 简介

《さんまのまんま》是1985年4月8日开始由富士台放送的“TALK·综艺”类节目。明石家秋刀鱼（日本著名搞笑艺人）的冠名节目。

节目地点设定在明石家秋刀鱼的自宅（豪宅）之中，每集请来一组嘉宾出演，在屋中展开各种各样的谈话。

本页收录的为AKB、SKE、乃木坂等做客秋刀鱼老师家的几集。
