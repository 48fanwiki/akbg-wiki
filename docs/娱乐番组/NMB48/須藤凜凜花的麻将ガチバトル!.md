# 須藤凜凜花的麻将ガチバトル!

## 简介

TBS channel 自 2015年8月8日（周六）深夜24：00 - 25：00播放的麻将对局节目。实际为两周播送，隔周重播的模式。形式为NMB的须藤凛凛花邀请各界知名人士前来对局。本节目为女偶像团体 所属NMB48的须藤凛凛花的冠名节目。

须藤凛凛花毕业后，由同属NMB48的村瀬纱英担任mc。
