# 攻克东京23区

## 简介

- 《攻克东京23区/难波抚子》（なにわなでしこ）是日本电视台于2011年7月12日至同年12月28日放送的综艺节目。

- 本节目是NMB48首个在京核心局的定期冠名节目，节目理念是概念是“NMB48 Meets TOKYO!”。

- NMB48成员们从关西出发，什么也不知道在东京进行外拍。每回在东京23区的一个区进行挑战外拍企划，并由此制霸东京。

- 出演成员：（每集大概由七名左右成员出演，所属Team为放送是所属）
Team N：小笠原茉由、門脇佳奈子、岸野里香、木下春奈、小谷里歩、近藤里奈、上西恵、白間美瑠、福本愛菜、松田栞、山口夕輝、山田菜々、山本彩、吉田朱里、渡辺美優紀
研究生：沖田彩華、城恵理子、矢倉楓子、木下百花、村上文香
