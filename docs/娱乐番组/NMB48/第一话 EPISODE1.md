# 第一话 EPISODE1

## 简介

- 节目内容为每集表演不同剧目的第一话，自2019年4月22日起每周日25:25~25:55在ABC电视台播出。
- 全12回播出结束后，由观众投票决定想要看“第2话”的剧目，最终排名第一将拍摄第2话。
- 第一季白间美瑠与村瀬纱英为每回固定出演成员；第二季渋谷凪咲与村瀬纱英为每回固定出演成员。
- 自2020年4月12日起播出第二季，因疫情原因推迟至7月12日开始播出。
