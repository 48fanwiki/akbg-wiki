# NMB48のナイショで限界突破!

## 简介

《NMB48のナイショで限界突破!》是由BSスカパー从2014年4月23日开始放送的综艺节目。

每集有6名NMB成员参演，为了创造出与别的偶像不同的特色，NMB成员们进行各种各样挑战的节目。

2014年4月至9月，节目为每月一集。10月份开始改为每月两集，第一、第三个周一晚2200-23:00（日本时间）放送。
