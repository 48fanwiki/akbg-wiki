# NMBのめっちゃバイト

## 简介

《NMB的非常打工》（NMBのめっちゃバイト）是关西电视台从2014年7月8日至12月23日于每周二深夜1:00 - 1:30（日本时间）放送的综艺节目。

本节目是成员们一边与当地关西人接触、融洽感情，一边进行打工的挑战性节目。

“偶像们认真地做这种事情真的好嘛？！”“偶像们进行这么严峻的挑战真的好嘛？！”

等让观众们产生“NMB真的要去做嘛？！”的惊讶之情的“非常规的打工”就是这个节目中成员们需要挑战的项目。

所以说这个节目就是让成员们通过“非常打工”来发现自己作为偶像的新的可能性的节目。（[日文维基](http://t.cn/Rwq0lCn)）
