# ぽくぽく百景もぐもぐ旅

## 简介

漫步百景吃货之旅（暂译名）为自2016年12月9日自ひかりTV的「Kawaiian for ひかりTV 4K」频道放送的旅行・综艺类节目。
该节目每期由NMB48的2名成员到日本全国各地旅行。由于该节目通常一镜到底，一般旅游节目中会被咔掉的移动过程，闲聊等均会播放。画质达到4K也是看点之一。
