# NMB48艺人（NMB48新番组）

## 简介

### 第一季、第二季

第一、二季节目的流程大致分为三部分：

- **校园情境喜剧**。故事设定于大阪女子中学“私立难波女学院”，学院中存在“搞笑部”、“女仆部”、“空姐部”、“美少女部”等很多奇怪的社团。故事围绕着搞笑部的部员们一边招募成员，一边朝着挑战女子高中生搞笑冠军赛的目标而努力的过程。第二季故事设定在比赛结束之后，因此改以“女子高中生搞笑漫才冠军赛”为努力目标。

- **后藤辉基主持的大喜利环节**。成员挑战各种不同的搞笑一发技，挑战的种类包罗万象。后藤除了吐槽成员的表演之外，也会在必要时讲解介绍搞笑技巧。

- **后半则有由不同的成员组合挑战漫才的演出**。节目最后一般由二至三名成员进行漫才表演。除了由几个固定搞笑组合外，也经常会以洗牌过的组合或和临时团体进行表演。

### 第三季

第三季大幅削减了情境喜剧环节，将时间留给即席综艺表演的环节。因此新一季的节目流程大致分为两部分：

- **与临时讲师学习搞笑环节**。邀请知名搞笑艺人现场指导成员们搞笑技巧，风格类似于HKT48的综艺节目《HKT48豚骨魔法少女学院》

- **足球时间主持的大喜利环节**。内容与前两季相似。

由于《艺人3》与《SKE48 炸虾商!》为同一团队制作，两节目预定要进行跨节目的合作企画。
