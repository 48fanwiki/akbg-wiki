# 姬太郎

## 简介

《姬太郎》（スター姫さがし太郎）是2010年9月11日至2011年9月24日，由东京电视台TXN系列放送的综艺节目。

本节目的主題是“跟拍”（密着）。总之就是对NMB48参加的各种各样活动进行跟拍。
