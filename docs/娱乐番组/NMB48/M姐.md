# M姐

## 简介

《NMB48山本彩の M-姉 〜ミュージックお姉さん〜》是从2013年11月30日开始放送的音乐类综艺节目，彩姐的冠名番組。

NMB48的山本彩与小林剑道作为主持人，迎来不同音乐类型的艺术家嘉宾，同时，椿鬼奴和其它NMB48成员也作为节目环节的常规出演者。

前三集为月更，2014年4月开始每周放送一集。档不全。
