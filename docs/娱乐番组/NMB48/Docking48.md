# Docking48

## 简介

《Docking48》（どっキング48）是2011年4月19日至2013年3月26日在关西电视台（关西地方）每周星期二24:35 - 25:30（日本时间） 播放的综艺节目。

作为NMB48最早的冠名节目，节目主要传递最新的影视情報以及成员的个人情报。一集主要分为一个主题内容+一个NMB成员们挑战的项目。

最大看点为每集的チャレンジ48（即挑战环节），每集主题部分出演人员为最新16人选拔组。
