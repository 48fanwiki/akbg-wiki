# 前田敦子のHEART SONGS

## 简介

《前田敦子のHEARTSONGS》是TOKYO FM从2010年4月5日开始每周一到周四晚放送的广播节目，2011年10月开始为21:50 - 21:55（日本时间）放送。

敦子会收听观众的来信，讲讲自己相关的一些事和给大家点播一首歌。每周二也会发送带图的电子报来给大家写写MESSAGE。
