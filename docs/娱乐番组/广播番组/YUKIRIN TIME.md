# YUKIRIN TIME

## 简介

- 《柏木由紀のYUKIRIN TIME》是TOKYO FM于2012年10月6日至2022年3月31日期间每周六晚24:00-24:30放送（后改为每周三晚27:00-27:30）的柏木由紀首個冠名定期廣播節目。

- 播放時段原節目為柏木所屬的French Kiss的广播節目《French Kiss的Kiss廣播》。
