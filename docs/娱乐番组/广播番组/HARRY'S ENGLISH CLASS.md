# HARRY'S ENGLISH CLASS

## 简介

- HARRY'S ENGLISH CLASS是J-WAVE电台节目《POP OF THE WORLD》里的一个栏目，每周六早上7:05~7:15播出。ハリー杉山和乃木坂46成员齋藤飛鳥搭档主持，跟大家一起学习英语。
- 2021年3月27日齋藤飛鳥MC毕业，由長濱ねる接替搭档MC。
- [节目官网](http://www.j-wave.co.jp/original/popworld/harrysenglishclass/)
