# 島崎遥香のぱるラジ！

## 简介

- 『島崎遥香のぱるラジ!』（岛崎遥香的帕露广播）是文化放送自2016年9月27日开始播出的广播节目，每周二日本时间21:00~21:30播出，島崎遥香一人出演，也是她的首个冠名电台节目。
- 节目由听众来信（念信）、帕露专栏（每期选一个不同的主题由露露对此发表看法）、帕露Q(回答听众提问)、帕露好事情（让露露感动的故事）四个环节构成。（[日文维基](http://t.cn/RVcZtVg)）
