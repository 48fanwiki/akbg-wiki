# SKE48＆HKT48のアイアイトーク

## 简介

《SKE48＆HKT48のアイアイトーク》是日本放送局自2013年10月2日开始放送的广播综艺节目。14年4月开始每周一晚20:30-21:00（日本时间）播放。

首周特别篇为HKT与SKE的代成员：松井玲奈与指原莉乃登场，之后为周替换形式，每周由两名成员担当。

每两周的各环节主题都是相同的，也就是说HKT与SKE进行挑战、竞争。哪边得到的分数多哪边就会得到一集SP的播放特权。
