# LISTEN?2→3

## 简介

- 『リッスン? 2-3』是从2015年6月30日开始在文化放送电台播放的音乐类广播节目，是『リッスン? 〜Live 4 Life〜』的后续节目，每周一到四深夜播出。其中周四的节目主持人由AKB48的次世代成员担任，一位成员出演一个月，每月轮换。
- 《[节目官网](http://www.mmqr.net/listen/)》《[日文维基](http://t.cn/R54n4Aw)》
