# Akb我們的故事

## 简介

AKB48的"我们的故事"（日语：AKB48の"私たちの物語）是AKB48（及姐妹组合）的成员隔周替换出演的广播剧，NHK-FM频率制作，2011年4月开始在隔周星期五正式播放至今。

内容主要根据来自听众小故事、关键字，由AKB48（及姐妹组合）的成员自己做脚本、编剧情，最终做成剧本并表演出来。

常规出演中，虽然没有标注，但每一集的声优出演仍然为“山寺宏一”。
