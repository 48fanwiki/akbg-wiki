# Evangelist School

## 简介

- エバンジェリストスクール!（~Evangelist School~ 科技科普师学园！）是从2016年4月2日开始在TOKYO FM播出的科技科普向电台节目。资深IT从业者西脇資哲，将跟助理主持若月佑美（乃木坂46）一起，在每周六晚间为听众送上最新的IT趋势，科技资讯，商业技能，以及采访和演讲技巧等各种主题的内容。
- [节目官网](http://www.tfm.co.jp/podcasts/eva/)
