# Akb all night nippon

## 简介

- 《AKB48のオールナイトニッポン》（AKB48的All Night Nippon）是AKB48家族在日本廣播電台「日本放送」的直播談話性節目。由于是深夜節目，所以只有18岁以上的成员才能参加。
- 2010年4月開播時在日本时间每周五深夜25:00 - 27:00（即周六凌晨1:00 - 3:00）播出，2014年4月起改于每周三深夜25:00 - 27:00（即周四凌晨1:00 - 3:00）播出。《[日文维基](http://t.cn/R5Qa1KA)》
