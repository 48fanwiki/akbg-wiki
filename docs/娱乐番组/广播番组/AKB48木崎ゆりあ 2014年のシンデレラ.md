# AKB48木崎ゆりあ 2014年のシンデレラ

## 简介

《AKB48木﨑ゆりあ 2014年のシンデレラ》（AKB48木﨑ゆりあ 2014年的灰姑娘）是MBS广播局制作的Talk类综艺广播节目。

于2014年10月2日开始，每周四深夜 0:10-0:40 （日本时间）放送，是木﨑ゆりあ的第一个冠名番组。[官网戳这里](http://www.mbs1179.com/ky48/)

节目内容：(好长的两句话......）

这是一个能让大家看到由SKE移籍到AKB，在东京第一次开始独自生活的木崎尤利娅在广播节目中不断学习各种各样的事情，努力变身为成年女性的努力模样的广播节目！

这也是一个随着还没有彻底成长为大人的高中生的木崎尤利娅，在广播节目中学习各种各样关于大人的事情，不断进行富有对话、企划、广播剧的“记录类广播节目”！
