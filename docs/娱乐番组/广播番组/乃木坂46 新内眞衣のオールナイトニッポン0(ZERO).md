# 乃木坂46 新内眞衣のオールナイトニッポン0(ZERO)

## 简介

- 「乃木坂46 新内眞衣的All Night Nippon 0(ZERO)」是从2016年3月31日（30日深夜）开始在日本放送播出的广播节目，由乃木坂46成员新内眞衣主持。
- 节目于日本时间每周四3:00 ~ 4:30（周三深夜）直播播出，不仅会在大气电波中进行广播，还会在Line Live上进行同步视频直播。
- 乃木坂46的其他成员除了会向节目投稿外，也会与主持人进行电话连线，甚至直接出现在直播室参与节目。
- 《[节目官网](http://t.cn/8sv9DwF)》《[日文维基](http://t.cn/RV0P2YQ)》
