# SKE 1+1≠2

## 简介

- “SKE48♥1+1は2じゃないよ!”（一加一不等于二哦！）是2010年11月9日开始由東海广播局放送的广播节目。现在播放时间为每周周一至周五21:30 - 21:40。

- “SKE48♥1+1+1は3じゃないよ!”（一加一加一不等于三哦！）是2011年4月17日开始由東海广播局放送的广播节目，现在播放时间为每周六22:00 - 22:30。

- “SKE48♥1×1は1じゃないよ!”（一乘一不等于一哦！）是2014年10月2日开始由東海广播局放送的广播节目，现在播放时间为每周日23:00 - 23:30。

- 官网：http://radio.commufa.jp/tokai/ske/index.html
