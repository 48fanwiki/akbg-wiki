# 週刊no3部

## 简介

- ノースリーブスの「週刊ノースリー部」是从2009年10月10日开始在日本放送播出的电台节目。
- AKB48的成員小嶋陽菜、高橋みなみ、峯岸みなみ向偶像界挑戰而組成的3人女子組合，組成至今數年已在四大巨蛋巡迴演出（只是設定），這是個把作為其原動力的少女們的成長・友情・韌性毫無保留的傳達，汗水與涙水的熱血記錄節目。
- 《[节目官网](http://t.cn/zYdmogJ)》《[日文维基](http://t.cn/R5ygaQc)》
