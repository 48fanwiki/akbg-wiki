# NGT48のにいがったフレンド!

## 簡介

**NGT48的新潟朋友！**（NGT48のにいがったフレンド!）

- NGT48第一個地上波冠名節目，2017年1月17日起開播，每週一深夜12時59分至1時29分在TV新潟（TeNY）播出。
- 2017年10月3日起也在富山縣的鬱金香電視台播出，時間為每週一深夜1時40分至2時10分。
- 主要內容為由主持人帶著NGT48成員們在新潟縣各地進行外景，部分集數會跨足其他都道府縣。
- 主持人為搞笑藝人組合LOTTI（中岡創一、小門建太郎）。
- 每次出演的NGT48成員人數不定，主要為3人。
- 由於只在地方台播放，所以片源不穩定，有可能缺檔或只有生肉。
