# 青春高校3年C组

## 简介

- 《青春高校3年C组》是テレビ東京自2018年4月2日起每周一至周五17:30-17:55播出的节目，节目企划为秋元康
- 出演：中井りか作为副担任（サブMC），メイプル超合金作为周一担任，バイきんぐ小峠、千鸟作为隔周周二担任，三四郎作为周三担任，おぎやはぎ、バカリズム作为隔周周四担任，日村勇紀（バナナマン）、柴田英嗣（アンタッチャブル）、飯塚悟志（東京03）作为隔周周五担任
- 2018年6月18日至6月22日这一周，中井りか因丑闻降格为学生（转校生名义），次周起恢复作为副担任（サブMC）出演
- 2020年4月起本节目改档至每周一深夜0:12-1:00播出，同时中井りか不再作为副担任（サブMC）出演
