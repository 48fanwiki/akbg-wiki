# HKT48の课外授业

## 简介

- 《コレカラ》是西日本电视台没周五深夜（周六凌晨）放送的综艺节目。

- 《HKT48の課外授業》是《コレカラ》中的一个单元，HKT成员们作为学生，在福冈体验各种各样的事情。

- 单元标题、内容与放送时间的变动：
2013年4月：HKT48の○○は××だ
2013年8月：HKT48と×
2014年1月：嘘ドルを探せ!?
