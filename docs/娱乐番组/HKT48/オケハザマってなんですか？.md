# オケハザマってなんですか？

## 简介

- 自2020年10月6日起每周二深夜（周三凌晨）25:25-25:55在九州广播电视台（RKB）播出的聊天型综艺，每一集请一位嘉宾（大多是来自企业的非艺能人）来讲述他们的人生经历，以及自己人生中决定胜负的关键事件，也就是“OKEHAZAMA”。第一集由HKT48的运营公司Mercury的社长前田昌治出演，从第二集开始，HKT48的运上弘菜、渡部爱加里、坂本爱玲菜三位成员轮流常规出演。
- 自2021年10月12日起播出第二季《OKEHAZAMA是什么～贰之阵・版图扩大～》
