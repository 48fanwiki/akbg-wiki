# HKT48のごぼてん!

## 简介

《HKT48的牛蒡天！》（HKT48のごぼてん!）是西日本电视台（TNC）2014年5月24日开始，每周六中午12：00-12:30播出的HKT48第一个常态性的日间冠名节目。

本节目以“让HKT48的成员们成为跟炸牛蒡乌冬面一样人见人爱的偶像”作为节目主旨，因此以“牛蒡天”作为节目名称。

节目的内容主要分为摄影棚内的段落，与一个称为“来决定受爱戴的center吧！”（愛されセンター決めちゃってん！）的外景采访单元。

棚内每集有七名HKT48的成员出席，有时邀请其他艺人担任特别来宾，成员们与特别来宾共同挑战看影片猜谜、实证网络话题新闻等活动。

上述主要段落外，每集片尾都有一个“指原的乌冬面”单元，指原会扮演炸牛蒡乌冬面摊的老板，一边煮面一边回答一位成员咨询的问题。

官网以及日文维基：《[官网](http://www.tnc.co.jp/goboten/)》、《[日文维基](http://ja.wikipedia.org/wiki/HKT48%E3%81%AE%E3%81%94%E3%81%BC%E3%81%A6%E3%82%93!)》
