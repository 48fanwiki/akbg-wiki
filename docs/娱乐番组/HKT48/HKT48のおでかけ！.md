# HKT48のおでかけ！

## 简介

宅姐领着萝莉们在福冈到处骗吃骗喝，四处钓wota

《HKT48的外出！》(HKT48のおでかけ！）是TBS电视台自2013年1月25日开播的深夜综艺节目，现每周三深夜12时58分播出。（[日语维基](http://t.cn/RwObRb8)）

本节目与《HaKaTa百货店》不同的是它并不在摄影棚内录制，而是主打以实际到福冈市内或郊区进行外景采访的方式，争取更多歌迷认同。

由于每次外景都是由8至22名HKT48的成员参与、人数众多，每集会指派一名“外出center”，负责带队、管理外出资金。

初期外景大多在特定地区进行巡游式活动，EP20起开始推出主题外景企画，如：露营野炊、在健身中心接受体能训练课程、在烹饪教室进行厨艺比赛等。

同时节目中仍有摄影棚内拍摄的段落，由指原莉乃担任主持人，后藤辉基担任讲评，两人一边进行无节操的对话一边针对外景影片进行解说吐槽。
