# HKT48口香糖魔法社

## 簡介

- 「瘋狂口香糖電視台」（クレイジーガム放送局，Crazy Gum Broadcast，縮寫為「CGB」）是零食糖果製造商樂天針對旗下口香糖類產品所進行的一個大型綜合廣告企畫，與樂天有長期廣告合作的HKT48也參與了此企畫。

- 配合CGB的推廣活動，HKT48成立了一個名為「HKT48口香糖魔法社」（HKT48ガムマジック部）的社團，由指原莉乃擔任社團顧問，宮脇咲良擔任社長，社員包括穴井千尋、多田愛佳、兒玉遙、下野由貴、田中菜津美、松岡菜摘、森保圓、田島芽瑠與朝長美櫻等人。

- 口香糖魔法社的成員們在搞笑魔術師藝人魔法師審司（マギー審司）的指導下，利用口香糖當道具進行魔術表演，並拍成短片投稿口香糖魔術錦標賽（ガムマジック選手権）。根據特定期限內各成員的上傳影片之點閱次數選出錦標賽的冠軍成員，並由排名領先的成員主演電視廣告。

- 第一屆錦標賽冠軍宮脇咲良獲得「博多氣球女孩篇」的主演資格，與其搭配演出的則為廣告曲《哈密瓜汁》的兩位選拔center田島芽瑠與朝長美櫻。
