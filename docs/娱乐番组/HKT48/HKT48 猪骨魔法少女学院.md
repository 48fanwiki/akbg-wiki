# HKT48 猪骨魔法少女学院

## 简介

《HKT48猪骨魔法少女学院》（HKT48トンコツ魔法少女学院）是日本电视台自2013年7月2日至2013年9月17日放送的深夜综艺节目。

本节目与其姊妹节目《NOGIBINGO!》(乃木坂46冠名节目)于每周二深夜25时29分播出，各30分钟，总共60分钟。

每集都有来自各领域的名人以“有趣”、“团体的未来性”、“想一起工作”的视点来决定两个节目的胜败，获胜的节目在下集会先播出。

节目设定为一个位于魔法国度中的“豚骨魔法少女学院”。学校中有一群魔法师实习生（成员们），在前辈的Center魔法师（指原莉乃）的带领下，希望通过锻炼成为能独当一面的魔法师。

每集最后会选出一名在当天节目中表现出色的“本周的最佳魔法师”，授予魔力胸针，得到的成员在日后演出时所拿的魔法棒造型也会跟着升级。

为了呼应节目背景设定的“魔法”这概念，在此节目中使用了不少电脑动画与灯光特效，是此节目与其他的HKT48综艺节目最大的不同处。

- 节目流程：
**开始时**，会有一段“本周的小剧场”，由不同的成员表演一段与成员平常的个性角色有关的魔法短剧作为开场。
**主环节中**，指原会从各领域请来伟大的魔法师（资深搞笑艺人）登场担任特别来宾。节目的流程会分为第一阶段的“对谈”（Talk）环节与第二阶段的搞笑特训课程。
**节目末尾**，会有一个由几位成员举行的小环节“HKT48认真反省会”，以聊天的形式反省自己的表现，作为该集节目的总结。

- 出演成员：
首席魔法使：指原莉乃
见习魔法使：  
穴井千寻、植木南央、多田爱佳、熊沢世莉奈、儿玉遥、下野由贵、田中菜津美、中西智代梨
