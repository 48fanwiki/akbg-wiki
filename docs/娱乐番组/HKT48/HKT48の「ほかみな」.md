# HKT48の「ほかみな」

## 简介

《HKT48の「ほかみな」〜そのほかのみなさん〜》是NOTTV从2014年5月20日开始放送的HKT48冠名综艺节目，是“AKB的你丫谁”（AKB48のあんた、谁？）的姐妹番组。无剪辑录播。

因为HKT48中，相比于支配人指原，其它成员知名度都比较低，所以成员们每回通过挑战各种各样的企划，努力成为“博多の顔”。

每回中最活跃的成员将被选为“MVF”（最優秀顔 - The Most Valuable Face），同时背景的黑白头像中，该成员将变为彩色。
