# HKTバラエティー48

## 简介

《HKT综艺48》（HKTバラエティー48）是九州朝日放送自2012年6月24日开始，于每月的最后一个星期日深夜1时20分放送的综艺节目。每集约半小时。（[日文维基](http://t.cn/RzaXUnC)）

此节目的主旨与名称相同，让HKT48的成员挑战各种不同的综艺企画，因此节目并没有特定的流程，但仍然有些比较常出现的单元不固定地出现在各集节目中。

有时特定的集别会有一个核心的主题单元，但也有整集节目都是以不同的小单元串成的情况。

在HKT48的第二期生于2012年10月28日播出的第五集节目中亮相之后，以一期生组成的Team H成员就逐渐淡出，成为以研究生为主角的节目。

但部分以中西智代梨为主、在团体间主打综艺担当的一期成员，仍然常在节目中登场，甚至拥有自己主持的小单元。
