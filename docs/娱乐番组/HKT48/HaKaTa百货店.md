# HaKaTa百货店

## 简介

《HaKaTa百货店》是日本电视台自2012年10月7日开始播放的深夜综艺节目，HKT成员为主要演出者，由指原莉乃主持，第一季共12集。（[日文维基](http://ja.wikipedia.org/wiki/HaKaTa%E7%99%BE%E8%B2%A8%E5%BA%97)）

由于第一季广受好评，追加播出了第二季，并命名为《HaKaTa百货店 2号馆》，于2013年1月26日深夜首播，同年3月30日播毕。

节目设定为福冈市博多（HaKaTa）的一家百货公司，专卖名为HKT48的偶像产品。指原莉乃担任推销员，每集邀请一位来自AKB Group中知名度较高的成员担任特别来宾。

指原会根据来宾的的个性，推荐适合的成员进行自我介绍、才艺表演。节目中段会推出一个根据来宾个性所定、由HKT48成员参与的比赛活动企画。

最后嘉宾要“选购”一位印象最深刻、想要选来当作妹妹的“首推成员”。获推成员可获赠推荐徽章，并会在片尾与来宾、指原一起进行博多美食约会。

第2季陆续加入了由成员们提议的单元活动，甚至直接由成员担任小单元主持人，如“中西Girls Collection”、“想让你更认识福冈”、“时间长度调整单元”等等。

与《AKBINGO!》等节目类似，本节目后半段也会插入一段歌曲影片，介绍HKT48相关动态，公演的片段、新歌曲的MV揭露、成员的个人新作等。

第三季（3号馆）于2015年1月12日开播，并将在HULU上配信。（[3号馆官网](http://www.ntv.co.jp/hakata/)）
