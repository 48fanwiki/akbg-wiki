# HKTシャカリキ48!

## 简介

《HKTシャカリキ48!》是2014年7月5日至12月26日由九州朝日电视台于每周六深夜0:55 - 1:25（日本时间）放送的打工类综艺节目。共26集，已完结。

福岡的偶像们——HKT48挑战各式各样的打工，并将所得的工资回报给一直以来应援她们的粉丝们。

由HKT48支配人——指原莉乃制定的返恩计划是，用这些钱做出HKT48原创的雨伞，并放在剧场里供观众们使用。
