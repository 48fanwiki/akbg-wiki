# AKB48 真夏の課外授業

## 简介

《AKB48真夏的课外授业》（AKB48真夏の課外授業）是富士台于2013年8月8日开始放送的[御台场合众国](http://www.fujitv.co.jp/newworld/index.html)的指南节目，共放送了三集。
