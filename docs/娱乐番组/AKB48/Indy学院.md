# Indy学院

## 简介

Indy学院（インディ学院）是日本电视台于2010年7月3日至9月25日放送的Mini番组，由走廊奔跑队部分成员出演，共12集。

主要内容为向成员（及观众们）传递Indy赛车的魅力，成员们会在节目中玩一些小游戏。（[官网](http://www.ntv.co.jp/indy/oa/)）

出演成员：仲川遥香、多田愛佳、平嶋夏海、渡辺麻友、菊地あやか
