# AKB48 VS IDOLING!!!

## 簡介

- AKB IDOLING!!!（エーケービー アイドリング!!!）是美女甜甜圈（IDOLING!!!）與AKB48成員組成的聯合組合。

- 2009年1月召開的「偶像冠軍 Push☆1」活動使兩個組合建立了聯合關係。雙方的選拔成員組成了組合並製作了樂曲，並在「IDOLING!!!」和「AKBINGO!」兩個節目中進行相互演出。
