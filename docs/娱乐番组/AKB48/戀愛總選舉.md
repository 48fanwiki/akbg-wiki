# 戀愛總選舉

## 简介

- 恋愛総選挙（れんあいそうせんきょ）2014年4月3日开始每周三深夜0:10 - 0:35（日本时间）由富士台放送。

- 节目初始定位是主持人土田晃之、指原莉乃与四名AKB48 Group的成员一边观看“兔派”的VTR一边谈论自己的恋爱观的恋爱Talk类综艺节目。

- 5月28日开始加入了“成员表白”与“Kiss倒计时”环节，与兔派环节隔周循环播放。

- 环节介绍：
兔派：在饭店等地汇集8-10名18岁以上单身男女，先凭借第一印象投票，经过两小时（无节操）的派对再次投票，互相投票的Couple就成立了。
表白：“AKB48惊喜告白”EP09开始，应募一般男性（必须死），派出成员前往指定地点，进行惊喜表白。
观吻：“Kiss 倒计时”开始时间同上，应募一般情侣，派出成员前往情侣家进行录像观摩，直到情侣kiss为止。

- 本节目于2014年9月24日晚播出最后一集，之后将由10月份播出的，由相同成员出演的相似节目《※AKB调べ》（AKB调查）接档。
