# ※AKB调べ

# 简介

- 《※AKB调べ》（AKB调查）是接档《恋爱总选举》，由富士台于2014年10月15日开始于每周三深夜0：10 - 0:35（日本时间）放送的综艺节目。

<!-- -->

- 出演人员：MC：指原莉乃、土田晃之；嘉宾：AKB48（GROUP）

<!-- -->

- 内容简介： AKB成员在总选举、节目出演、公演站位中一直作为”被选择”的存在...平时都是站在被粉丝们、Staff们选择的立场上。 但是，这样的他们，将在这个节目中进行选择，站在”主动选择”的一侧。看了这个节目你就能更了解她们啦。

<!-- -->

- 官网及维基：《富士台官网》、《日文维基》
