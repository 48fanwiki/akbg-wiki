# AKB48 サヨナラ毛利さん

## 简介

- 与AKBINGO!的制作人毛利忍泪别，改由新世代AKB成员及新STAFF班参与制作，并翻新以往人气企划，冀创造出令和时代的王道偶像综艺
- 日本テレビ（NTV）自2022年4月7日起每周四24:59-25:29（周五凌晨0:59-1:29）播出
- MC：霜降り明星、峯岸みなみ
- 为纪念番组播出，于2022年4月3日（周日）在Pia Arena MM举行特别演唱会（请戳 **这里**），由观众投票选出番组Center为大盛真步
- 除电视播出外也在Hulu上配信，并且于Smash和Showroom上配信番外，Smash番外内容为每集两位成员的私服check，Showroom番外内容为毛利P拍摄的番组录制期间花絮
