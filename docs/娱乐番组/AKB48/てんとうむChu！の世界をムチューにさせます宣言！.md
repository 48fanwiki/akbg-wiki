# てんとうむChu！の世界をムチューにさせます宣言！

## 简介

《小瓢虫Chu!的让全世界都迷上宣言！》（てんとうむChu!の世界をムチューにさせます宣言！）是日本电视台于2014年4月15日至7月8日播出的综艺节目。每集30分钟，共12集.

本节目目的为让这些年轻成员们接受各种从未尝试过的综艺试炼，培养出综艺反应、采访报道能力等偶像、艺人必备的专业技能。

与“小瓢虫Chu”主演电视节目女子高警察不同的是，《女子高警察》主要以喜剧短剧型态表现，而本节目则是第一个真正的综艺节目。

节目流程大致可以分为两部分：“主企画”与短篇动画“昆虫物语 小瓢虫Chu!与小蜜蜂Chu!”。为了呼应“全世界”的标题，许多企画都以不同国家命名。

此外，因为成员分属不同团队，有各自的活动行程，时有成员会缺席。
