# なぎさちゃんのミライ！トライ！ティービー

## 简介

《渚沙酱的未来TRY TV》（なぎさちゃんのミライ！トライ！ティービー）是AKB48 Team 8坂口渚沙的冠名番组。

番组由UHB北海道文化放送于每周日11:45～11:50（日本时间）放送。（[官网戳这里](http://uhb.jp/program/nagisa/)）
