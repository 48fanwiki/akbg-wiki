# 横山由依的优雅巡礼

## 简介

- 《横山由依（AKB48）的优雅巡礼》是关西台于2012年7月18日开播，每月播放一集，由出身于京都府的横山实地走访故乡的名胜，介绍京都当地的传统文化的节目，此节目是横山由依第一个个人冠名节目

- 第一季《京都‧美的音色》于2013年6月19日完结，同年7月17日播出第二季《京都 色彩日记》，于2020年12月13日完结。

- 在《横山由依（AKB48）的优雅巡礼》 节目中，她首度以个人主持外景采访的方式，在每次节目中选择京都的一个特定地区，进行较为深入的散步寻访，或是选定特定主题，在京都各地拜访相关的人物、机关或地点。节目的内容包含了景点的介绍，访问当地的店家与相关的专家，或是介绍试吃各地的传统或特色食物等。

- 第一季《京都‧美的音色》与一般旅游节目不同的是强调了“声音”，不管是景点或是人物采访，都以独特的声音作为话题起点，再扩及到周遭环境的文化历史之美。

- 此外在每集节目的末尾都有一个“由依的日记”小环节，展示数张以横山的视角所拍摄或选择的照片，搭配简短的手写感言与旁白，总结该集节目的内容。

- 第二季《京都 色彩日记》则改以“颜色”作为核心话题，每集末尾维持第一季“由依的日记”小环节，但是以横山手绘的绘图日记来回顾并总结该集内容。

- 编辑推荐：也許有飯會覺得有點沉悶 不過我覺得這是akb在目前電視節目裡面最高水準的作品 大推薦!（光看风景感觉都很棒！）

- 官网&维基：《[KTV官网](http://www.ktv.jp/hannari/index.html)》、《[日文维基](http://t.cn/RAYowP1)》
