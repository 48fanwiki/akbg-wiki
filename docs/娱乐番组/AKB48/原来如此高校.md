# 原来如此高校

## 简介

《原来如此高校》（なるほど!ハイスクール）是日本电视台系列自2011年4月21日至2012年3月8日于每周四19:00 - 19:56（日本时间）放送的综艺节目。

由于2010年5月30日・10月9日放送的特別节目广受好评，本节目决定常规化。宣传口号是 “学员募集中！”。

2011年10月20日开始以《真实？仿冒？综艺节目 原来如此！HS》（ガチ?ガセ?バラエティー なるほどHS（エイチエス））的节目名放送。

本节目主要内容将一般学校没有教授的知识，通过AKB48的成员身体力行来呈现给观众。

由伦敦靴子2号田村淳担任班主任，Peace担任副班主任，テリー伊藤则是理事长，学生则是AKB48和NMB48的成员，青木沙耶加等人则轮流担任OG（Old Girl）。

《真实？仿冒？综艺节目 原来如此！HS》则以“看穿充满世间的谎”为主题，以各种单元检证某些东西是真实还是仿冒。同时，节目中新设惩罚环节。

虽然本节目已于2012年3月8日完结，但实际上是以将于同年4月20日开始逢星期五19:00 - 19:56播映的新节目《真的假的》的形式延续。
