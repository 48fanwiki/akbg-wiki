# DHCキレイを磨く！エクストリームBeauty

## 简介

- 《DHCキレイを磨く！エクストリームBeauty》（DHC磨砺美丽！极度Beauty）是由DHC Television制作，2018年10月1日-2019年3月27日每天13:00-14:00在Youtube和Niconico放送的时尚番组。

- MC是元桃草的伊仓爱美，此外每天有不同的偶像作为常规Guest出演，其中小栗有以作为每周一的常规Guest出演。
