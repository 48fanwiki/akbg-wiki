# AKB影像Center

## 简介

《AKB映像中心》（AKB映像センター）是富士台于2013年4月22日至9月29日，每周日深夜0：55分（日本时间）放送的综艺节目，是《[AKB自动车部](http://t.cn/R76AkcR)》的后续番组。

MC为指原莉乃，并由Lily Franky担任讲评来宾，节目共有24集，除最后一集是加长播出的半小时特集外，其余各集片长皆为15分钟。

节目是由YouTube的母集团Google独立赞助，与YouTube进行跨业合作，采用现场直播进行的综艺节目（偶有录播）。直播布景是可拆卸的，每周会在富士台总部内不同位置移动。

每周指原会介绍三至四个由成员自主创作、主演与投稿的短片，短片会上传至AKB48在YouTube的官方频道，并会通过点击数排名选出“映像Center”（Video Center）。

短片的内容除了常见的AKB48活动花絮之外，也有像是成员的居家生活披露、才艺表演、特别制作的搞笑短片或是歌唱与舞蹈等内容企画。

其中，有为数不少的影片是由成员们与YouTube上具有高知名度的创作频道，或影片创作家所跨界合作。
