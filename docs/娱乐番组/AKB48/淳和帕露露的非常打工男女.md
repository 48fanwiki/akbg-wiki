# 淳和帕露露的非常打工男女

## 簡介

《淳和帕露露的非常打工男女》（淳・ぱるるの○○バイト!）是2015年4月14日开始，每周二深夜25:30 - 26:00（周三凌晨1：30 - 2：00，日本时间），由富士台放送的综艺节目。

本节目内容为介绍日本全国‘超级可爱的打工女孩’和‘超级帅气的打工男子’，为之应援并加以吐槽的相亲类节目。

本节目为田村淳与島崎遥香的冠名节目，同时也由两人担任MC。这也是岛崎遥香第一个冠名节目、第一次担任节目MC。

节目于2016年3月完结，共45集。

官网&维基：《[富士台官网](http://www.fujitv.co.jp/b_hp/atsushiparuru/)》、《[日文维基](http://t.cn/RAYaBZU)》
