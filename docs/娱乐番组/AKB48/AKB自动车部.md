# AKB自动车部

## 简介

《AKB汽车社》（日语：AKB自動車部）是富士台2012年4月28日至9月22日间每周六深夜放送的的一个与汽车相关的由AKB48冠名并主演综艺节目，丰田汽车独立赞助。

《AKB汽车社》的节目契机，是起因于**前田敦子**参与了丰田汽车的电视广告演出。

但是直到2012年的成人式为止，包括前田在内AKB48集团所有已经成年、有资格报考申请驾驶执照的成员中，竟然没有任何一位实际拥有汽车驾照。

因此在秋元康的指示下，成立了“AKB汽车社”，以全体23名成员都考取汽车驾照作为社团活动的目标，并且贴身跟拍其过程，作为节目的内容主轴。

除此之外，制作单位也邀请了许多拥有汽车驾照的名人，以“拥有汽车的生活”为主题，与AKB48的成员一同进行开车兜风的外景。
