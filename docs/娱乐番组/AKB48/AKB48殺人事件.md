# AKB48殺人事件

## 簡介

- 本作品登場的AKB48成員包括13期的研究生，截至2012年5月末的時候在籍者全員（SKE48兼任的松井珠理奈、NMB48兼任的渡邊美優紀、虛擬偶像江口愛實除外）。因此，連載開始前的2012年6月16日轉到HKT48的指原亦有登場。

- AKB48在8月畢業的前田敦子在AKB畢業後想做的工作是偵探。這樣，前田與AKB48的成員是AKB最後的工作時在孤島遭遇殺人事件。嫌疑犯是AKB的全部成員。偵探前田為了解開謎團，把真正的犯人找出來。

- 與『アイスの実』合作的CM，根據實際成員出演CM亦順著公開・播放。而且，出演成員誰都不知道犯人是誰，到最後才會告知。全5回

- 为了配合新CM的推出，讲述前田侦探在89名成员（5月末的成员阵容，除去兼任的成员，包含第13期研究生在内的AKB48总人数）中寻找真凶的全9话漫画连载《AKB48杀人事件》将从2012年7月4日发售的《周刊少年SUNDAY》上闪亮登场。负责作画的漫画家为梧桐柾木。
