# フレンチキスのキス旅

## 简介

《FrenchKiss的Kiss旅》（フレンチ・キスのキス旅）是2014年7月1日至9月23日由东京电视台放送的海外旅行番组。（[日文维基](http://t.cn/RwGLjbI)）

フレンチ・キス（FrenchKiss）组合的三人（柏木由紀、高城亜樹、倉持明日香）各自挑战个人海外女子旅行，并传递旅行乐趣的情報节目。

这是フレンチ・キス的第一个冠名节目。
