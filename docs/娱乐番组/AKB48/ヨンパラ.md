# ヨンパラ

## 简介

《ヨンパラ FUTUREゲームバトル》是由TBS电视台放送，NOT YET主演的综艺节目。通称“ヨンパラ”。

出演者：Not yet（大島優子、北原里英、指原莉乃、横山由依）

ヨンパラ 是从AKB48派生出的组合Not yet的常规番組。因为成员非常忙碌，经常分散在各地，所以四名成员使用Skype进行视频通话。

成员之间会在主持人主持下进行一些游戏，游戏的胜者可以获得“ヨンパラ金貨”，集齐10枚就可以实现这个人一个愿望。
