# 僕らが考える夜

## 簡介

- 《我们反思的夜晚》（僕らが考える夜）是2015年4月16日开始，每周三深夜24:25 - 24:55（日本时间）由富士台放送的综艺节目。

- 本節目是作为MC的指原莉乃、土田晃之，与4名AKB的成員，就日本社会上的各种问题加以讨论，还有“大叔世代”的代表人物以犀利的视角对这些问题进行分析。

- 官网&维基：《[富士台官网](http://www.fujitv.co.jp/b_hp/bokuragakangaeru/)》、《[日文维基](http://t.cn/RAjdXXz)》
