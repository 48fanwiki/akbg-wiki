# 爆笑學園

## 简介

- 『爆笑学園ナセバナ〜ル!』是2012年10月9日到2013年2月26日在TBS电视台系列播出的综艺节目，是搞笑艺人组合爆笑問題的冠名节目。
- 这是一个在网络上向全国各个学校以及学院募集情报，节目组再把收集到的情报向全国发表的一档给年轻人应援的节目。（[日文维基](http://t.cn/RcYdpnd)）
- MC：爆笑問題（太田光・田中裕二）
