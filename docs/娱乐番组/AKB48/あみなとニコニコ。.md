# あみなとニコニコ。

## 简介

“亚美菜和NICONICO”（あみなとニコニコ）是NICONICO动画“竹书房”频道网络放送的网络综艺节目，2011年3月24日开始至2013年3月29日。

出演成员为AKB48成员佐藤亚美菜和声优白石稔。两人进行与动漫相关的各种企划的挑战

Vol.1～Vol.60为每周四放送、Vol.61～Vol.70每月第二、第四周五放送、Vol.71〜Vol.75每月一次生放送（直播）。

好多Vol待补。
