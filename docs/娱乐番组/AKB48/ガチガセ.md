# ガチガセ

## 简介

《真的假的》（ガチガセ）是日本电视台于2012年4月20日至2013年2月8日放送的综艺节目，是2012年3月8日完结的《原来如此高校》的续篇。

以生活中身边的事情为主题，进行“是真”还是“是假”判断的游戏或小测试。

起初为AKB48组合与别的组合的团队对抗战，但从2012年10月开始由于组合的变化，对抗形式转变为个人战。

节目在2013年2月8日迎来了完结，并于同年2月15日放送了特别节目 “这里很奇怪啊！AKB48传言的真相全部回答SP！”。
