# AKB48+10!

## 简介

AKB48+10!是在Enter371自2007年10月2日至2009年9月5日期间放送的综艺节目。

AKB48的常态冠名节目，是主要以元TeamB成员出演并进行各种企划的节目。

AKB48+10中“10”的意思是，AKB“48”做出“48+10=58”分钟的节目。
