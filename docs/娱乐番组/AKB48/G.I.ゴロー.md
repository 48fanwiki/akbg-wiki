# G.I.ゴロー

## 简介

- 『G.I.ゴロー』是2010年4月5日到9月20日期间在TBS电视台播出的深夜综艺节目，是SMAP稲垣吾郎的冠名节目。（[日文维基](http://t.cn/RcJPYIA)）
- 节目从第二集开始每集会有两名AKB48的成员作为AKB女仆登场。
