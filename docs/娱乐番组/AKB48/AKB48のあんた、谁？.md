# AKB48のあんた、谁？

## 简介

《AKB48的你是谁？》（AKB48のあんた、誰？）是日AKB48在NOTTV上播放的冠名综艺节目之一，节目自2012年4月2日开始每周周一至周五直播。

东京都秋叶原车站前的“AKB48 CAFE&SHOP AKIHABARA”内的剧场区域开始公开直播，由AKB48成员4名和MC2人出演，每回播放给30名的一般观众（事前抽选制、收费）。

节目内容是成员一边在粉丝的面前挑战各式各样的企划一边继续呼吁个性的东西。此外，这个节目与Google+连同展开节目内容的企划。

因为播放形式特殊，档源获取很难，所以相较节目期数总数来说，熟肉比较少。（[日文维基](http://t.cn/zldVbiD)）
