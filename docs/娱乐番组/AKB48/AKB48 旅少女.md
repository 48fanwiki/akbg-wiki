# AKB48 旅少女

## 簡介

《AKB48旅少女》是2015年4月5日开始，每周六深夜24:55 - 25:25（日本时间），由日本电视台放送的综艺节目。

本节目是AKB48 Group中，平时关系很好的数人（3、4人）进行的旅行中谈话记录类节目。

放送结束后，含有未放送部分的完全版《AKB48のただ今、移動中!》将在Hulu进行放送。

官网介绍：（《[NTV官網](http://www.ntv.co.jp/tabishojo/)》、《[日文维基](http://t.cn/RAjuHoy)》）

每天都作为“偶像”奋斗着的AKB48 Group成员们，在这里进行像私下里一样的，与好朋友一起享受时光的旅行。有着意外的共同点的成员们、同期的成员们等等，她们之间会产生怎么样的对话呢？本节目会挑选让人心跳加速的成员组合们进行放送！返回到作为普通少女的她们，“自己的素颜、藏在心底的真心话、对于将来的不安、以及AKB48 Group的未来是什么...”，并非作为偶像，而是作为一个少女，进行全新的真心话对话记录类节目！此外，观察移动车内的成员们的样子的环节《AKB48のただ今、移動中!》也将放送（Hulu）。移动中放松的成员们的真正素颜、真心话谈话、以及各种意外事件都能看到哦！
