# さしこのくせに

## 简介

- 2011年1月11日（真是个好日期）开播的《明明就是个小指子》是撒西的第一个冠名番组，也是“小指子”“34ko”“345”这一荣誉称号的由来之处。

- 《明明是个小指子》的主旨是一个以小指子的养成为目标的综艺节目。节目开播之时，小指子也正站在“废柴”的顶峰傲视群雄。

- 节目在播出后也引发了轰动，创造了极为坑爹的收视率。但是，这却不耽误它成为大家口中的——入坑神番。详细介绍[（戳这里）](http://tieba.baidu.com/p/3121700395?see_lz=1&pn=1)
