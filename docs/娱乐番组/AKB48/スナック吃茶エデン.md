# スナック吃茶エデン

## 简介

《快餐咖啡店伊甸园》（スナック喫茶エデン）是富士电视台于2012年10月21日至2013年3月24日，每月1回不定期放送的深夜音乐综艺节目，共6集。

节目中每回都有嘉宾来访，以休息室脱口秀方式进行，并且还将让嘉宾在披露与自身形象大相径庭的曲目新感觉的音乐综艺节目。

设定为靠近天空树附近，东京某车站前的小巷中的小吃店咖啡馆“伊甸园”中，有个不相称的舞台，每天访问的人会唱自己爱的歌。

利利·弗兰克饰演咖啡店老板りりーさん  
**高桥南**饰演老板的女儿、咖啡店看板娘みなみ  
**小嶋陽菜**饰演老顾客、陪酒屋“舌吻”头牌なぎさ  
**峯岸南**饰演附近的无业者、みなみ的青梅竹马みいちゃん  
 铃木浩介饰演店员すずき  
小室哲哉饰演老顾客兼卖不出作品的小说家こむろさん。
