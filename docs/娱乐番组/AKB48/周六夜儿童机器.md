# 周六夜儿童机器

## 简介

《周六夜儿童机器》，又译作《周六儿童夜现场/周六幼齿夜现场》（サタデーナイトチャイルドマシーン）的企画起源，可以回溯至为了配合新单曲唱片[《So long!》](http://t.cn/R7IPmnN)的发行而在日本电视台上播放的同名短篇电视剧，由AKB48的Team A、Team K与Team B三个分队分别负责一天分的演出内容，并由观众票选出表现最好的一集。Team B赢得观众票选的冠军，因而获得分组专属节目的权利。

企画主轴设定为“**大人时段播放的儿童节目**”，**但其实内容并不是设定给儿童收看，而是模仿儿童节目的画面与桥段，加入大量大人才看得懂的恶搞与黑色幽默所制作出的综艺节目**。

## 主要单元

**开场**

人员为小嶋阳菜所扮演的“小惠”与搞笑艺人大水洋介配音的布偶角色“户斗田”，“小惠”是小嶋与导演福田曾经合作过的电视剧《小惠你会用魔法吗》中的角色。

**PARUPARU的自己做来玩**

由岛崎遥香扮演的“PARUPARU”与穿着著玩偶装的大水洋介所扮演的“慢吞吞君”（ぐずぐずくん）所演出的单元。原本单元的主旨是要利用现场准备好的材料，由岛崎示范如何自己动手做出常见的童玩，但实际上却总是在现场即兴发挥随便乱做而失败。单元的最后则会有正确的示范，做出原本计划完成的玩具。

**说故事……给你听**

由柏木由纪穿着著性感的套装与网袜作成熟女教师打扮的“由纪姊姊”朗诵童话故事的单元。虽然故事主题是“浦岛太郎”“小红帽”等知名的童话但内容却经过改编，故事中的人物都使用成人的角度对话与思考，而变成截然不同的黑色幽默内容。

**找出不对劲的地方**

以短剧形式演出的喜剧单元，让观众在短剧中找出三个不对劲的地方。短剧以家庭餐厅作为场景，由梅田彩佳、大场美奈与加藤玲奈三人主演，扮演“不交男友同盟”的成员。三个不对劲点之中通常有两个很容易看出，但第三点却是隐藏在画面根本看不出的地方，是恶作剧的猜谜游戏。

**用身体记得现代用语**

由成员穿着紧身衣以做体操般的风格表演一些单字。虽然原本是儿童节目常见的单元，但因为选择的都是一些很艰深儿童绝对无法理解的用字，利用反差感产生笑点。

**大家的歌曲单元**

由Team B成员演唱歌曲的单元，虽然歌曲的音乐和舞蹈风格与儿童节目中常见的唱歌单元类似，但由导演福田所撰写的歌词内容却充满著比较适合成年观众的讽刺或恶搞。

**呐，很不可思议吧？**

渡边美优纪的个人短片单元。其剧情是模拟渡边的男友在夜里到她住处拜访、以男友的第一人称视角所拍摄的妄想短片。虽然渡边在短片里常会以暧昧的口气对着镜头说话让观众误会，但这其实是个在房间里现场表演科学实验（例如利用过冷水制造出冰笋、或是靠筛网跟水的表面张力让倒置水杯中的水不会洒出等）的单元。
