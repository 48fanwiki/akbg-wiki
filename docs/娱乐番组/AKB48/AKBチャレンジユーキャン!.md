# AKBチャレンジユーキャン!

## 简介

《AKB的挑战你行的》（AKBチャレンジユーキャン!）是AKB成员为“ユーキャン”公司（通信、教育出版类）做的一个广告宣传类节目

既有普通的CM广告，也有横山由依、川荣李奈等进行资格证挑战（药剂、药膳等）的报导连载。
