# AKB子兎道场

## 简介

《AKB子兔道场》是东京电视台于2012年12月7日至2014年3月28日每周五17:30 － 18:00（日本时间）放送的综艺节目，是《周刊AKB》的后继节目，共66回。

节目中欢迎有烦恼的兔子（成员）来到摄影棚，并由AKB48成员亲身聆听烦恼、议论、相谈并引导解决。

MC：峯岸みなみ、テリー伊藤；此外会有9名其它AKB48成员出演。（[日文维基](http://t.cn/Rwqy93u)）
