# ○○编集社

## 简介

《○○编集社》（○○編集社）是西日本电视台2013年10月26日 - 2014年3月29日，每月最后一个周六放送的节目，是《指原P》是后续番组.

番组的主要内容是调查验证现在备受注目的各种○○，一月一集，共6集，于2014年3月29日完结。
