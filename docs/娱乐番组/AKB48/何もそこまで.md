# 何もそこまで

## 简介

AKB48短剧《何もそこまで…》是2013年7月26日至2014年3月21日由“光TV”放送的AKB48冠名综艺节目。

《微妙》之后，AKB48出演的搞笑滑稽短剧节目第2弹。
