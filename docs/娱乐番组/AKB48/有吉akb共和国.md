# 有吉akb共和国

## 简介

《有吉AKB共和国》是TBS电视台2010年3月29日开始放送的综艺节目，2014年3月31至今的播放时间为周一深夜（周二凌晨）2:16 - 2:46（日本时间）

节目主持人是有吉弘行和小嶋陽菜。另外，每周都会更换AKB正规成员与研究生各数名出演。（[官网戳这里](http://www.tbs.co.jp/ariyoshi-akb/)）（[过往放送内容](http://www.tbs.co.jp/ariyoshi-akb/backnumber/)）

节目的原始宗旨是“研究生育成番組”。
