# AKBでアルバイト

## 简介

《在AKB打工》（AKBでアルバイト）是富士台2014年7月1日至12月23日每周二深夜1:40 - 2:00（周三凌晨，日本时间）放送的综艺节目（[官网戳这里](http://www.fujitv.co.jp/akb_arbeit/index.html)）

设定：AKB48突然缺了录制节目的人员，两个人出门寻找可以替代成员参加的普通人~~主要还是看AKB成員们变装啦。
