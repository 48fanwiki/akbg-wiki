# AKB的人生论

## 简介

《AKB的人生论》是2013年4月5日开始每周五朝日新聞推出的电子版访谈视频。（[官网戳这里](http://www.asahi.com/culture/idol/akb_opinion/)）

从2014年4月开始，每个月最后一周周五会以乃木坂的《人生论》取代。
