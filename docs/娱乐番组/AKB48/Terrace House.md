# Terrace House

## 简介

《二层公寓》（テラスハウス、Terrace House）是富士电视台于2012年10月12日开始每周星期五的23:00－23:30（日本时间）播放的真人实境秀。

一个由男性3人、女性3人在同一个家中居住（3个月的期间限定）的恋爱综艺节目。

本页所列为本节目的第一季（Season 1），放送时间为121012 - 121228，共12周，**北原里英**出演。
