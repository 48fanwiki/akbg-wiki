# AKB観光大使

## 简介

AKB观光大使是2013年5月23日-2017年3月23日由富士台放送的综艺节目，每月一集。（[官网戳这里](http://www.fujitv.co.jp/otn/akbkankoutaishi/index.html)）

算是旅行科普节目，每集有两个成员去旅游，体验当地活动，宣传当地特色等等。
