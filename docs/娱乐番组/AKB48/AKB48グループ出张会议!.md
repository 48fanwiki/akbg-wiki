# AKB48グループ出张会议!

## 简介

- 富士电视台CS放送，每月最后一个周三21:00播出。
- “绝对的十人”：鈴木くるみ、田口愛佳、千葉恵里、西川怜、前田彩佳、矢作萌夏、久保怜音、山内瑞葵、佐藤美波、岡田梨奈。
- 第1、2、3、5回由上述十人中的三位出演，拜访48Group的各据点，带*者为该回议长。每回流程为：两位前辈成员面试该回出演的三位成员并选出该回的议长→三位成员前往分团剧场与分团出演成员进行课题讨论→三位成员与分团代表成员拜访分团当地某处代表地。
- 第4、6、7回由各姊妹團派三名代表到AKB48劇場拜訪。議長由AKB48"絕對的十人"成員之一擔任, 帶*者為該回議長。每回流程为：姊妹團三位成员前往AKB剧场与AKB隊伍出演成员进行课题讨论→本部代表成员招待姊妹團三位成员乘坐悍馬加長型轎車到附近豪華地方再作交流。
- 本番组的前导是2018年6月18日播出的《生放送！AKB48 紧急会议》（[观看请戳这里](http://www.bilibili.com/video/av31306171/)）
