# 微妙

## 简介

《微妙〜》（びみょ〜）是光TV于2011年9月29日至2012年2月23日制作并放送的AKB48短剧节目，共20集。

本节目为AKB48和光TV的大型合作企划，亦是AKB48首个正式短剧节目。秋元康主编的各式各样的短剧，由AKB48的成员进行挑战。

一集会播放5至7个短剧，短剧后会有制作花絮，然后会有“接下来的短剧是这个”或“短剧还在继续”等成员的声音带到下一个短剧。

第8集开始有SKE48的成员加入演出，后续节目《AKB48的真格挑战》于2012年6月29日开始播出。
