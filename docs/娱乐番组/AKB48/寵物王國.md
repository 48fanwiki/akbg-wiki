# 寵物王國

## 简介

《宠物王国Wonderland》（ペットの王国 ワンだランド）是朝日电视台2014年10月5日开始每周日9:30〜10:00（日本时间）放送的综艺节目。

节目内容为跟拍取材、介绍一般人或艺人们充满原创的宠物生活。

MC：関根勤、篠田麻里子
