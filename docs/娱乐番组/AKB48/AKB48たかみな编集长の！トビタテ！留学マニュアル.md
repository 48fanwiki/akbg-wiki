# AKB48たかみな编集长の！トビタテ！留学マニュアル

## 简介

《TAKAMINA编辑长的！飞出国门！留学指南》是2014年2月13日 - 3月20日由BS电视台放送的一个留学知识科普类节目。

高桥南与AKB成员作为“飞出国门”留学指南编辑部的成员，每集派出两名记者对留学人士进行访谈。
