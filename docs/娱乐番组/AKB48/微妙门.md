# 微妙门

## 简介

《光TV presents 微妙～的门 AKB48的真格挑战》（ひかりTV presents びみょ〜な扉 AKB48のガチチャレ）是光TV于2012年6月29日至2013年3月22日放送的综艺节目。

由于节目全名较长，一般习惯简称为真格挑战（ガチチャレ）。本节目是在2011年9月29日至2012年2月23日播放的《AKB48“微妙”短剧》的后续节目。

AKB48成员挑战苛刻试练，为成员发现新的可能性。每回有两位成员二人挑战难题，练习过程在节目以记录方式播放。

本节目可让观众在事前预测AKB48成员的挑战结果，在“ひかりTV×AKB48”特设网站投票“成功”或“失败”

答中者将以抽签形式得奖，获得AKB48成员亲手料理的晩餐会（EP36、EP37）。
