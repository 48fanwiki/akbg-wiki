# NHK高校讲座 日本史

## 简介

Mion，瑞希和琉克（向井地美音、土保瑞希、込山榛香）三人的固定番组，身为高中生和AKB48成员的她们，要在节目中学习历史，成为历史系偶像-。-

每节课的学习Memo请戳→→→“[官网](http://www.nhk.or.jp/kokokoza/tv/nihonshi/)”←←←，点PDF图标查看。

有心思学日语或日本历史的一定要看一下，讲的还是很不错的。
