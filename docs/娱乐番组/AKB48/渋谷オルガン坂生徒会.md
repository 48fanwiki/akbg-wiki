# 渋谷オルガン坂生徒会

## 简介

- 《渋谷 #オルガン坂生徒会》（渋谷 #Organ坂学生会）是由DHC Television制作，2019年7月28日起每周日日本时间17:00放送的时尚番组。

- MC是横泽夏子。下尾みう作为常规成员出演。
