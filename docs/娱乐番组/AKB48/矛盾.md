# 矛盾

## 简介

《矛盾大对决》（日语：ほこ×たて）是日本富士电视台的交战型综艺节目，2011年1月17日开始播出，2013年10月，因节目制作过程不当，宣布停播。

节目以矛和盾有关的典故“矛盾”为基础，让持有相反“绝对○○”自信的双方在一个平台上直接分出高下的综艺节目。

但是，此节目不仅仅为了对抗，最重要是使对抗双方可以在各自领域不断的以“更好”为目标。

在节目的起首，会先说明对抗的内容和分别简要介绍一下“矛盾”双方。之后双方会在名为“MAX PERFORMANCE”的环节中演示自己的实力。

在看过“矛盾”双方的演示录像后，各个专业领域的嘉宾学者会依照录像进行解说和预计对决‎的结果，当集嘉宾就要参考录像和嘉宾学者的说法，估计哪边会胜利。

最后“矛盾”双方就会依照定下的内容作正面对决‎分出高下。

**大岛优子**为常任嘉宾之一，猜测胜率为47%
