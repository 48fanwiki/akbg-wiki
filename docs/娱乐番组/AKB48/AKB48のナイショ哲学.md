# AKB48のナイショ哲学

## 简介

- 千叶电视台每周日晚24:00-24:30（周一凌晨0:00-0:30）播出
- 每集3位成员出演，根据各种主题披露偶像技能的秘密哲学，由MC决定获胜者，另有直播APP MIXCHANNEL节目助手活动评选出的前4位出演节目，第1名为副MC，第2名为AD，第3、4名现场参观节目收录
- 前3集节目名称为《Team8的秘密哲学》，从第4集起改名为《AKB48的秘密哲学》，其他姐妹团出演时节目名称也会做对应修改
- MC：Identity
