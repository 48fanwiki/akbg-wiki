# 板野パイセンっ

## 简介

虎牙冠名番组《板野パイセンっ》（板野辈前），是TBS于2014年4月27日至9月21日放送的综艺节目。（[官网戳这里](http://www.tbs.co.jp/itanopaisen/)）

节目主持由板野友美和小岛琉璃共同担当，每期都有好玩有趣的企画。

其中SP01（TOMO呼唤朋友）可以看做节目的前身，SP02是节目限定复活SP。
