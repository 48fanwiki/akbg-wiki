# AKBとXX

## 简介

《AKB和××!》（AKBと××!）是读卖电视台的综艺节目，从2010年7月13日开始播出至2016年3月22日，每月一集。

节目是AKB48在关西地方的首个冠名节目。内容主要围绕AKB与××的事情，而××就是指那些与AKB一起的人和事。

节目最初以AKB48成员与关西事物的点滴为主，后来在2011年4月至2012年11月，进行了AKB48、SKE48和NMB48间的“XX选拔”。

官网及维基：《[官网](http://www.ytv.co.jp/akbxx/)》、《[日文维基](http://t.cn/RwbFVQd)》
