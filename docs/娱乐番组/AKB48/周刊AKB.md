# 周刊AKB

## 简介

《周刊AKB》（週刊AKB）是东京电视台2009年7月10日至2012年11月30日，于每周五17:30 - 17:59放送的综艺节目。

节目中每集由两名成员作为值日主持，主导节目进行。Speedwagon作为“顾问”出演。

广告标语是“AKB的为了AKB而制作的关于AKB的节目”，这个意义亦包括AKB的姊妹团体。周刊AKB与BINGO不同的是周刊以外景为主。

从09年9月27日至10月25日，以‘别册周刊AKB’的名义播出了5集的总集篇（待补）。2010年1月2日，播出了名为‘周刊AKB特别号’的特别节目（待补）。

2012年11月30日，周刊AKB完结。2012年12月7日起在同时间的新节目《AKB子兔道场》开始。
