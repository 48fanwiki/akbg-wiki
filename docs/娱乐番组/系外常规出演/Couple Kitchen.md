# Couple Kitchen

## 简介

《Couple Kitchen》（カップルキッチン）是以“女子力很高的天使系男子”与“男子力很高的男前系女子”假想结婚为背景的料理类综艺节目。（[官网戳这里](http://www.fujitv.co.jp/otn/couplek/)）

夫妇扮演者：千葉雄大、秋元才加

每集会有不同嘉宾参与。
