# 新堂本兄弟

## 简介

《新堂本兄弟》是富士台的音乐类综艺节目。原名《堂本兄弟》，于2004年10月17日更名，进入《新堂本兄弟》阶段，于日本时间毎周日深夜23:15－23:45播出，2014年9月28日完结。

《堂本兄弟》于2001年4月8日开始播出，时间是22:00－22:30，共三十分钟。节目每周邀请一组（一位）来宾，以进行谈话、趣味单元与歌曲现场演唱为主要流程。

出演AKB成员：**高桥南**。（其它成员有时作为嘉宾出现）（[日文维基](http://t.cn/RwMV0sm)）
