# 爆笑 大日本アカン警察

## 簡介

《爆笑大日本坑爹警察》（爆笑 大日本アカン警察）是富士台于2011年4月24日至2013年9月8日每周日19:58 - 20:54（日本时间）放送的综艺节目。

“アカン”是关西的方言“駄目だ”（不行）的意思，但“アカン警察”并不是说警察不行，而是一群艺人扮演成警察，

将从日本全国收集来的“アカン情报”以VTR的形势表现出来，然后判定是否真的是“アカン”

MC:濱田雅功、松本人志
