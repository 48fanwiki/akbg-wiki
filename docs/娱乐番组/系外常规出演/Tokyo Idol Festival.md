# Tokyo Idol Festival

## 簡介

- Tokyo Idol Festival为富士電視台TOKYO IDOL PROJECT自2010年開始每年夏天在东京台場舉辦的日本國內最大女偶像活動，簡稱TIF。Live在Hot Stage、Smile Garden、Sky Stage等各处舞台进行，除Live外还有各类Talk、游戏互动活动。
- 指原莉乃自2017年起连续担任每年TIF的Chairman（主席）一职，并担任TIF联动番组この指と〜まれ!的MC。
- 2018年4月首度在泰国曼谷举办海外站。
- 2020年由于疫情原因推迟至10月举办，且形式为线上。原定出演的HKT48由于成员村重杏奈确诊感染新冠而取消出演，由STU48代替出演。
