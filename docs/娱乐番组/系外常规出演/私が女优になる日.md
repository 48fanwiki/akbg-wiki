# 私が女优になる日

## 簡介

- TBS电视台以全国10-19岁的女性为对象，为发掘并培养将来在电视剧中活跃的女演员，于2020年12月发表了“TBS明星培养计划《我成为女演员的那一天》”并举办了甄选会，从2021年1月开始经过第一次文件审查、第二次远程面试、第三次见面面试，最终12名合格者被选出，其中10名出演者发表：赤穗华、饭沼爱、冈田里穗、涉谷风花、**高仓萌香（元NGT48）**、高桥七海、武山瑠香、出口真帆、肱冈加那美、三浦凉菜、伊藤美优（合格，不出演）、乾らいむ（合格，不出演）

- 节目策划为**秋元康**，该企划以最终审查为中心，制作追踪审查过程的贴身节目。在最终审查中胜出的人将作为项目成员而活动，为了成为女演员而参加了广泛的教育课程。预定出演电视台制作团队亲手制作的连续剧，通过培养期间的活动审查适合性，决定角色分配（挑战的电视剧的第1弹预定为青春群像剧）。
