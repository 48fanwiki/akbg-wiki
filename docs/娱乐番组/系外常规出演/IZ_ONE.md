# IZ*ONE

## 簡介

- IZ*ONE為《PRODUCE 48》最終出道團體，由韓國觀眾擔任國民製作人，投票決定12名成員，包括張元英、宮脇咲良(HKT48)、曺柔理、崔藝娜、安宥真、矢吹奈子(HKT48)、權恩菲、姜惠元、本田仁美(AKB48)、金彩元、金珉周、李彩燕。
- 活动时间为2018年10月至2021年3月14日。

## 播放

- 編列以48系成員為主!接受共演的視頻。**除音樂類外只收錄有中文字幕的視頻**
