# Viking

## 简介

- 《Viking》（バイキング）是富士台自2014年4月1日起平日（周一至周五）日间（11:55 ~ 13:00）直播的情报类综艺番组，是《笑笑又何妨》的后续番组。自2020年9月28日起，改名为《Viking More》（バイキングMORE），平日（周一至周五）日间（11:55 ~ 14:45）播出。

- 川栄李奈自2014年4月2日到2015年7月21日期间周三常规出演，山田菜菜自2015年3月30日至2015年12月21日期间周一常规出演，山本彩自2014年4月4日至2017年3月31日期间周五常规出演，高桥みなみ自2020年10月7日起隔周周三常规出演。

- 《[节目官网](http://www.fujitv.co.jp/viking/index.html)》《[日文维基](http://t.cn/RqsLIWr)》
