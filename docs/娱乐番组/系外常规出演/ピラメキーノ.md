# ピラメキーノ

## 简介

- 『ピラメキーノ』（PIRAMEKINO）是从2009年4月6日到2015年9月30日在东京电视台播出的儿童节目。（[日文维基](http://t.cn/R5qdeTI)）
- 乃木坂46成员生駒里奈从2013年5月15日开始作为节目固定班底出演。
