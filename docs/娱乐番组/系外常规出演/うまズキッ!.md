# うまズキッ!

## 简介

- 《うまズキッ!》是富士台2013年1月5日开始，于每周六深夜1:05 - 1:35（日本时间）放送的竞马情報综艺节目。在2016年12月24日終了。
MC：小嶋阳菜、白石麻衣、小木矢作等
- 《馬好王国〜Umazukingdom〜》是富士台2017年1月7日开始，接替前述节目再度以新MC賽馬節目姿態登場，這次不只改版連主MC都換人。
MC：DAIGO、堤礼実、小嶋阳菜、白石麻衣
- 2018年3月25日是白石麻衣最后一期，松村沙友理接棒担任新MC
- 2020年3月21日是小嶋阳菜、松村沙友理最后一期
