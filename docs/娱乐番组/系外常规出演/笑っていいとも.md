# 笑っていいとも

## 简介

《森田一义时间 笑一笑又何妨！》（森田一義アワー 笑っていいとも!）是日本富士台从1982年10月4日至2014年3月31日间播出的综艺节目通称“笑一笑又何妨！”，由塔摩利主持。

该节目是塔摩利唯一以本名（森田一义）主持的电视节目，同时与其在朝日电视台主持的《塔摩利俱乐部》同为播出长达32年的长寿节目。

2014年3月31日，该节目播出最后的完结特集篇，瞬间收视取得33.4%的佳绩，为32年的播出历程画上了完美的终止符。

**指原莉乃**为2011年10月－结束时的常规成员。（开始为周三常规成员，2013年10月移动至周一常规成员）

AKB GROUP其它成员也时有出演。
