# 今夜比一比

## 简介

- 今夜くらべてみました（今夜比一比）是日本電視臺2012年开播的深夜訪談節目。每集都會請到三位來賓，針對不同主題來比一比。節目中會穿插妄想小劇場，以及節目慣例的跟拍小單元，可以看到明星們私底下和螢光幕前不同的風貌，讓人大呼過癮。《[日文维基](http://t.cn/Rci1Ii2)》《[节目官网](http://www.ntv.co.jp/konkurabe/)》

- 节目原本由後藤輝基、徳井義実、SHELLY三人MC，从2016年2月9日开始**指原莉乃**接替休产假的SHELLY成为节目第二位女主持人，从2018年7月11日开始，SHELLY复归，四人一同担任MC。
