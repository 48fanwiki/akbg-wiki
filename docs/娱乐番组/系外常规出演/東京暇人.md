# 東京暇人

## 簡介

『東京暇人』（とうきょうひまじん、TOKYO hi-IMAGINE）是从2012年10月6日开始在日本テレビ每周六晚2:23-3:08放送的综艺番組。

松井玲奈于2016年4月-12月（平野绫留学期间）、2017年3月25日至今担任本番组的MC。
