# ラストアイドル

## 簡介

- 最後的偶像（日語：ラストアイドル）是朝日電視台聯播網從2017年8月13日開始播出的偶像選秀節目，時間檔為日本時間每周日凌晨 0:05 至 0:30，總製作人為秋元康。同時，由本節目誕生並於2017年12月20日出道的女子偶像組合亦為同名

- 第二季開始由指原莉乃擔任其中一名導師,並由橫山由依擔任MC
