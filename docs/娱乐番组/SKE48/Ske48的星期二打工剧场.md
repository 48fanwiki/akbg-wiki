# Ske48的星期二打工剧场

## 简介

- 《SKE48的星期二打工剧场》（SKE48の火曜アルバイト劇場）是CBC电视台从2014年7月2日开始于每周二深夜1:18 - 1:48放送的综艺节目，共25集，已完结。

- 节目内容为SKE48的成员们在东海三县进行实际存在的有意思的打工工作。（[日文维基](http://t.cn/RwhFQER)）
