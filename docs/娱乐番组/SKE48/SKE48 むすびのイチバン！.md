# SKE48 むすびのイチバン！

## 簡介

- 由東海電視台2017年4月份在深夜播出的SKE48冠番節目『SKE48 むすびのイチバン！』,番組主要進行想與東海地區的人們結緣,成為更讓人喜愛的偶像為主旨,每期由數名成員共同出演。

- 主MC:平成ノブシコブシ(吉村崇 徳井健太)
