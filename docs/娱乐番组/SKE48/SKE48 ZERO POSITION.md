# SKE48 ZERO POSITION

## 简介

- 《SKE48 ZERO POSITION 〜チームスパルタ!能力別アンダーバトル〜》是TBS Channel 1 于2014年10月4日开始，每两周周六晚11:00-11:30（日本时间）播出的对决类综艺节目。

- 主要内容为成员就某项主题进行对决，如唱歌、跳舞、料理等，然后由审查员（对决内容方面的专家）审查，决定出“Zero Position”（Center，参考公演站位）。

- 成功获得Center的成员，不仅能获得自我展示的时间，对决胜利的结果也将写入官方成员介绍当中。（[日文维基](http://t.cn/RwNyfJF)）（[节目官网](http://www.tbs.co.jp/tbs-ch/ichioshi/ske48zeroposition/)）

- 初代MC：须田亚香里、松村香织、谷真理佳

- 二代MC：高柳明音、北川綾巴、後藤楽々

- 三代MC：高柳明音、北野瑠華

- 四代MC：北野瑠華、井上瑠夏
