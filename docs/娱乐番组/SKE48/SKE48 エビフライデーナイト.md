# SKE48 エビフライデーナイト

## 简介

《SKE48的炸虾周五夜》（SKE48のエビフライデーナイト）是日本电视台自2013年10月5日至同年12月21日播出的综艺节目，每集30分钟。

搞笑艺人大久保佳代子担任本节目主持人。与一般日本综艺节目中主持人角色不太相同，作为此节目灵魂人物的她在节目中担任“大久保制作人”（大久保P）角色，除了在每集的节目中设定喜欢的课题让SKE的成员进行挑战外，也会根据成员们当集的表现以自己的独断意见在节目末尾安排成员们在雏坛上的站位，命名为“大久保选拔”。

SKE48向来是以努力型偶像的团体风格自居，在综艺能力上逊于其他姊妹团体。因此，《炸虾周五夜》的节目企画主旨就是希望能透过主持人大久保的协助，开发SKE48成员的综艺能力，甚至从其中挖掘出新的综艺王牌。因此，大久保选拔会无视各SKE成员的入团期数、歌迷票选总选举排名等既有的资历与知名度指标，单纯就成员们的综艺能力表现作评价。

《炸虾周五夜》的后续节目《SKE48炸虾商！》于2014年7月15日开始播放。
