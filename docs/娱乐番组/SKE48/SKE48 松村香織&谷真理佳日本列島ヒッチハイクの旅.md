# SKE48 松村香織&谷真理佳日本列島ヒッチハイクの旅

## 簡介

- 节目简介：  
《SKE48 松村香織&谷真理佳日本列島順風車之旅》（SKE48 松村香織&谷真理佳日本列島ヒッチハイクの旅）是《SKE48炸虾商》的內置環節，由7月29日開始，於影視網站Hulu上配信。  
由於時間關係，《SKE48 炸虾商！》節目中只會播放刪剪後的片段，所以完整版影片需要在Hulu上觀看。

- 节目内容：  
於第三集的《SKE48 炸虾商！》拍攝結束後，松村香織與谷真理佳被電波少年的制作人帶離現場，於酒店渡過一晚後出發前往機場，再乘坐飛機到稚內去。  
兩人後來被告知要進行順風車之旅，要以坐順風車的方式從日本最北端之地(北海道稚內市的宗谷岬)開始，終點為SKE48於名古屋的劇場。  
她們身上只有基本的物資和兩萬日元，旅程中的住宿和飲食安排都要自行負責，總計大約1700公里的旅程就在這樣的情況之下開始。

- 出演者：  
チームE：須田亜香里(於應援影片中出現)、谷真理佳  
研究生：松村香織
