# SKE48学园

## 简介

- 《SKE48学園》是由2009年10月3日开始在Sky PerfecTV!的エンタ!371播放的综艺节目，是SKE48首个冠名节目。

- 节目内容为成员透过学园的设定、以“授业”和“部活”名义展开各种企划。

- 节目一开始为Team S出演，后来Team KⅡ、E、研究生也有出演。EP27之后改为每集5~6人出演。

- 目前仍在连载中，每月一集。

- [日文维基](https://ja.wikipedia.org/wiki/SKE48%E5%AD%A6%E5%9C%92)
