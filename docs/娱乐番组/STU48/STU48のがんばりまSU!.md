# STU48のがんばりまSU!

## 简介

- 由新广岛电视台(テレビ新広島)播出的地上波综艺节目。最初于17年8月、9月播出了两集1小时特番，从17年10月起成为30分钟固定月番(每月最后一个周二深夜播出)。
- 每集节目由两组成员进行各种对决，胜利的一组获得下一期节目的出演权(201811前)。
