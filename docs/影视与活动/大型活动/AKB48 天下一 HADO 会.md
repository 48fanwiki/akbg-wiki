# AKB48 天下一 HADO 会

## 简介

- AKB48 AR Sports HADO Team対抗
- 比赛规则：
前两季每一季6个比赛日，每个比赛日每个Team三位成员共计12名成员出席，每局比赛90秒时间，对战双方各上场两位成员。4个Team分成两组各比赛三局（第三局前根据现场粉丝投票，票数多的一方第三局可使用大招），按三局累积比分决出胜负，胜的2个Team和负的2个Team再各比赛三局，按三局累积比分决出胜负（第三局前根据现场粉丝投票，票数多的一方第三局可使用大招），诞生1234名给予不同积分。6个比赛日结束后按累积积分决出赛季最终的1234名。每个比赛日的第一名Team奖励成员旅行，第一季最终的第一名Team奖励队歌MV拍摄，第二季最终的第一名Team奖励冠名广播番组。另有17期生与staff/职业电竞手的表演赛，17期生获胜会有特别奖励。
第三季起每一季12个比赛日,第四季因取消Team制度按照期别分组，第五季前召开Draft会议成员自由组队。
- HADO赞助冠番《AKB48、最近可能听了吗？》及《AKB48、最近听了吧…》每集播出比赛内容精选
