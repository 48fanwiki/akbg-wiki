# AKB48 小分队单曲 PV 合集

## Team Surprise

- 为AKS与京乐产业合作的弹珠机发售而组成的临时组合。每一代成员拍摄了12+4首全新PV，在AKB48的弹珠机台与网络上，分两年以每周一首的速度进行Team Surprise公演。
- 第一代：2012年8月，披露了第一代的Team Surprise，包括已毕业成员前田敦子。在下表的演唱成员名单中，标示“*”号者为该曲的中央位置（center）成员，所有全员曲以前田敦子为center。
成员：渡辺麻友、宮澤佐江、大島優子、島崎遥香、篠田麻里子、高城亜樹、前田敦子、北原里英、松井玲奈、峯岸みなみ、指原莉乃、横山由依、板野友美、小嶋陽菜、柏木由紀、高橋みなみ
- 第二代：2014年6月，披露了第二代的Team Surprise，包括已毕业成员篠田麻里子、板野友美与大岛优子。在下表的演唱成员名单中，标示“*”号者为该曲的中央位置（center）成员，第1与第16首全员曲以大岛优子为center，第12和第13首全员曲以渡边麻友为center。
成员：島崎遥香、渡辺美優紀、渡辺麻友、山本彩、小嶋陽菜、高城亜樹、大島優子、北原里英、松井玲奈、峯岸みなみ、指原莉乃、横山由依、篠田麻里子、板野友美、柏木由紀、高橋みなみ
- 第三代：2017年9月，披露了第三代的Team Surprise，包括部分毕业成员在内共100人，其中TOP成员16人。
TOP成员：高橋みなみ、渡辺麻友、小嶋陽菜、川栄李奈、島崎遥香、松井玲奈、渡辺美優紀、山本彩、宫胁咲良、指原莉乃、柏木由紀、松井珠理奈、加藤玲奈、小島真子、入山杏奈、横山由依
