# PON!

## 简介

- 《PON!》（ポン）是2010年3月29日开始由日本电视台于平日（周一至周五）10:25 - 11:30（日本时间）直播的情报类综艺节目。2016年3月28日开始改为周一到周四播出。

- 现在的常规出演成员有小嶋阳菜（星期三）。

- 篠田麻里子在2010年4月到2016年3月期间作为周三固定成员出演。

- NO3B部分为10-11年节目的一个环节合集，即NO3B带领大家尝美食。

- 其他成员部分多为几分钟的小片段，具体人员内容请看下表。
