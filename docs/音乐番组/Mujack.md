# Mujack

## 简介

MuJack（ミュージャック）是关西电视台（KTV）播放的音乐情报节目。2014年4月11日开始每周五深夜1：45 - 2：15放送。

高桥南是本节目的第4代女性MC，从2010年7月8日开始担任至今。这也是她首次担任电视节目的MC。

顺带一提，第二代MC是秋元才加（2008年4月18日 - 2009年4月3日）
