# ハマスカ放送部

## 简介

- OKAMOTO'S的贝斯手濱田郁未与乃木坂46的斋藤飞鸟的新节目「HamAsuka放送部」（每周四深夜2：16~2：36）将于10月7日开播。
- 濱田作为电台DJ备受赞誉，而斋藤尽管拥有极高的人气，其真实面目仍然充满谜团。由这两人主持的「HamAsuka放送部」是一档在“广播台”特有的愉快气氛中，进行天南地北的闲聊，围绕音乐开展各种活动的节目。
